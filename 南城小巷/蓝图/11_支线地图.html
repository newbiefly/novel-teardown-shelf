S1 · 南久事业成长线

定位：全书第二骨架，"女主硬本事逆袭"的核心卖点载体；与感情线并行，是南久"不依附"的底气来源。

  • 起（[第9-10章]）：南久"给爷爷打工"、正式管账，一把揪出逃单客，显"对钱的敏感+经营无师自通"的天赋（叶老爷子与宋霆对视一眼，眼里均有讶色[第9章]）；随即提议茶馆入驻网络平台、打造独立 IP[第10章]——事业意识的萌芽。
  • 承（[第13章]→[第27-29章]）：独当一面拆穿假洋人李玮、抢先报警硬刚[第13章]；大三在星耀代课，递企划书被林颂耀"只给口头肯定"、认清其为"冷静的猎人"[第29章]；主动断联宋霆后，转身以"快闪+随舞"办成个人首场大型活动、拉来赞助、谈下商场中庭[第29章]。
  • 转（[第35-37章]）：进入社会，冲击星耀旗舰店合伙人席位、拒绝30万"捷径"[第35章]；为30万四处碰壁（亲妈家受辱、后妈以彩礼相待），向宋霆开口获无条件相助、发现旧卡十万[第36章]；从"装修小白"熬成工地"包工头"，与林颂耀、丁骏结成"铁三角"[第37章]。
  • 又一转（[第40-54章]）：被爷爷"斩根"后彻底告别过去、全面掌舵星耀向综合演艺集团转型[第40章]；反手在民政局掉头、以股权文件与林家把柄反将林颂耀[第53章]，率律师团与"人墙"逼退审计队、坐实"星耀的引领者与灵魂所在"[第54章]。
  • 合（[第55章]→[第70章]）：签股权转让、应下"离开酆市"，带成熟运营经验、行业资源与一笔巨款退场，"条条大路通罗马，我只是换条路走而已"[第55章]；在南城重选址、筹备工作室，最终自营"南风艺境"、任全国舞蹈大赛评委[第70章]。
  • 与主线交汇点：① 事业是"不依附"的筹码——宋霆每次相助（电脑[第8章]、银行卡[第27章]、30万[第36章]）都反衬南久"要自己站稳"的执念；② [第50章]南久以"手机待办清单"划下星耀红线，明确"不允许宋霆碰星耀"——事业成为两人边界谈判的筹码；③ [第55章]回归南城 = 事业让位于"跟他在一起"的选择。
  • 进度：已收束（[第70章]自营"南风艺境"，事业闭环）。
  • 相关伏笔：V27（上平台做IP→[第30章]由宋霆维护）、V93（30万门槛→[第36章]凑齐）、V95（自立之志→[第70章]回收）、V146（"换条路走"→[第70章]回收）。
  • 续写抓手：南久新工作室与宋霆茶山事业线的联动（"南风艺境"×"山色共居"[第62章]）；郑坤一系南城人脉[第62章]、老街招商线[第9章]可作新商战引子。

S2 · 林颂耀线（商战 · 情感三角）

定位：男二线，兼具"情感三角"与"商战对手"双重功能；提供"利益婚姻/精英算计"的商业理性视角，与主线的"纯粹救赎"互为镜像。

  • 起（[第27章]）：星耀老板林颂耀训斥下属，南久为其泡茶留印象，他追问她换手机与"男朋友"；[第29章]由"只看口头肯定"的上司转为"审视者"。
  • 承（[第35-37章]）：以30万入股门槛试探南久、被拒[第35章]；结成"铁三角"后，以"我可以将星耀的经营权给你"为筹码，提出契约婚姻（感情只是调味品、双赢）[第37章]；[第39章]借参观林盛康集团推进"见家长"，其父评南久"心里有谱、能成事"[第39章]。
  • 转（[第42-43章]）：歪脖子树下强吻南久"验证"隐秘、当众羞辱"都叫乱伦"，被南久以拳头还击、划下底线彻底反目[第42章]；次日瞥见南久颈间吻痕、撂话"他不行"，婚约名存实亡[第43章]。
  • 又一转（[第53-54章]）：领证当日南久在民政局掉头，以股权文件与林家把柄（父亲私生子、大哥伴侣）反将[第53章]；他率律师与审计团队突袭星耀、封锁财务，却被下属层层"人墙"逼退，惊觉正失去她与星耀[第54章]。
  • 合（[第55章]→[第70章]）：以"离开酆市"为唯一条件、高价收购南久全部股份、把未列入股东退出协议的业务也量化为补偿款，体面分手[第55章]；登门酆市与宋霆正面交锋、车内视线悍然相撞[第69章]；以婚戒改制的钻石项链作别、"物归原主"，两年后成为低调务实的家族企业接班人[第70章]。
  • 与主线交汇点：① [第37章]契约婚姻 = 主线"分道扬镳"的外部压力源；② [第42章]强吻逼出秘密 = 主线决裂"以后不要再见面了"的直接导火索；③ [第53-54章]商战 = 南久"拆伙应战、退股返乡"的前置条件，为主角二人重逢扫清障碍；④ [第69-70章]情敌相撞与项链作别 = 主线圆满的"对照参照"。
  • 进度：已收束（[第70章]项链作别）。
  • 相关伏笔：V78（打量与兴趣）、V81（审视加深）、V94（视为潜在对手/璞玉）、V96（契约婚姻→[第53章]回收）、V113（掌握秘密→[第54章]回收）、V178（情感收束→[第70章]回收）。
  • 续写抓手：林颂耀家族企业/资本线可作番外或新篇的"旧对手"；婚戒改制项链[第70章]为开放式余味。

S3 · 南家家族线

定位：主线的"伦理障碍"来源；提供市井家族群像（爷爷/父母/后妈/堂弟/姑妈）。

  • 起（[第1-3章]）：南振东、廖虹把南久当累赘送来送去；爷爷收留并管教（教规矩、勒令"叫宋叔"）——隔代庇护与管教并存的基调。
  • 承（[第9-12章]）：茶馆继承权之争浮出——婶婶"怕南久占好处"派南乔宇回馆盯梢、撬门霸房[第11章]；爷爷点破"怕南久占好处"的动机[第12章]；爷爷心中对子女不和的"心头刺"（亲叔叔借钱旧怨）[第9章]。
  • 转（[第38-40章]）：南老爷子大寿、家族近十年最齐的一次团聚[第38章]；南乔宇推门撞破南久与宋霆私情，爷爷打落茶杯、斥"礼仪廉耻"、逐南久离巷、两记拐杖狠抽宋霆"把这不该有的心思断干净"[第39章]；电话"你以后没事就不要回来了"斩断归途[第40章]。
  • 又一转（[第41章]）：爷爷与南久谈婚事、"你结婚我就不去了"，送别；饭桌上宋霆与林颂耀暗锋[第41章]。
  • 合（[第55章]→[第68章]）：南久回归定居[第56章]；爷爷从审宋霆[第63章]到"过完中秋再说"[第63章]、口头默许[第64章]；中秋家宴当众宣布"从今往后，宋霆就是咱们自家人了"[第68章]，并怒斥南振东"从小到大，你管过她几天"[第68章]。
  • 与主线交汇点：① [第1章]爷爷收宋霆为干儿子 = 名分障碍的源头（V2，[第68章]回收）；② [第39章]撞破驱逐 = 主线由"秘密"转向"被斩断"的总爆发；③ [第68章]当众"自家人" = 名分障碍的正式解除，主线得以完婚。
  • 进度：已收束（[第68章]公开、[第69章]婚期压到中秋后、[第70章]完婚）。
  • 相关伏笔：V2（干儿子/名分→[第68章]回收）、V26（子女不和的心头刺，未回收）、V33（继承权之争→[第35章]部分回收）、V76（爷爷隐约警觉→[第39章]回收）、V100（南乔宇撞破→[第39章]回收）、V102/V108（"你结婚我就不去了"，未回收）。
  • 续写抓手：南老爷子"你结婚我就不去了"暗桩未回收——婚礼现场"老爷子是否到场"可作番外/续写的情感落点；南乔宇继承茶馆问题[第35章]未解。

S4 · 宋霆茶山经营线

定位：男主的事业与身世载体，也是"双向救赎"的兑现场（南久在 [第43-52章] 反过来救他的茶山）；茶山群像（珍敏/老八/芹婶/桑丫/姜清/大黄）由此聚合。

  • 起（[第2-3章]→[第17章]）：第2、3、6章反复出现宋霆"下个礼拜再去趟山里"、"山里刚起步"[第2/3/6章]；[第17章]首次揭开"山里"真相——宋霆的茶山（仓库+茶厂+茶垄），初见芹婶、珍敏、老八、大黄狗。
  • 承（[第18-26章]）：茶山之夏，南久随宋霆上茶山、劳作、教桑丫跳舞[第19-20章]；芹婶讲他"卷铺盖住茶园、一片片摸叶子、半夜听雨打茶叶"的执着[第21章]；珍敏的彩礼钱之谜与朱家旧债[第21-23章]；朱家掳人事件[第23-24章]，茶山线第一次与"社会线"交汇。
  • 转（[第43-47章]）：宋霆赴庭庄谈生意彻夜未归、电话失联，老八托人报"茶山茶农大打出手"[第43章]；南久赶回主事、被珍敏认作"宋老板爱人"[第43章]；拍板"与天争"抢采、立军令状[第45章]；赴黑石洼村借工[第46章]；宋霆车祸濒死获救、独身赶回茶山[第47章]。
  • 又一转（[第51-52章]）：现钱抢采平怨、许诺带桑丫出山[第51章]；宋霆撕损失担保协议、备避孕药放南久走[第52章]。
  • 合（[第62章]）：宋霆搬出木屋、推倒重建"山色共居"（通透空间、露台、廊檐、壁炉、院落、大狗），为将来南久同住做打算；以"你嫂子"向姜清界定南久身份[第62章]。
  • 与主线交汇点：① [第17章]茶山是两人"独处"与"知根知底"的环境（[第18章]隔门板谈心）；② [第43-52章]南久主事茶山 = 双向救赎的核心兑现（她替他的生意托底）；③ [第46章]珍敏道出"宋霆当年为她挨打"的真相 = 主线感情分量的加码；④ [第62章]"山色共居" = 主线"共度余生"的物质象征。
  • 进度：主线已收束，"山色共居"尚未建成（V162未回收）。
  • 相关伏笔：V5/V7（"山里"之谜→[第17章]回收）、V63（茶园木屋→[第62章]回收）、V120（借工→[第46章]回收）、V123（魏村长受礼，未回收）、V50（老八开沟，未回收）、V51（后备箱零食，未回收）、V162（山色共居，未回收）。

S5 · 身世创伤线

定位：全书情感合法性的地基——解释"为什么是这两个人"；一条双向的"原生家庭创伤"线。

  • 起（[第1章]）：南久被父母踢来踢去、只身百里寻爷爷[第1章]；宋霆出现于荒道的缘由未交代（V3）[第1章]。
  • 承（[第6章]→[第18章]）：李崇光泄露"宋霆他爸把他妈杀死了"[第6章]（全书最深的身世暗线）；[第18章]宋霆隔着淋浴间门板剖白"我在你身上能看见小时候的我"，并提"你爷爷从前在我最困难的时候拉了我一把"。
  • 转（[第34章]）：结尾回溯——宋霆十七岁那年站上河岸、前路尽毁，南老爷子在堤坝上一把攥住他手腕"孩子，跟我回家"，给了他第二次生命（V16/V52/V53在[第34章]集中回收）。
  • 合（[第18章][第70章]）：创伤不"治愈"而"互照"——"我在你身上能看见小时候的我"[第18章]落地为全书"双向救赎"主题；[第70章]收束"遇见她之前，尽是漂泊的孤岛……唯见朝阳为他轰然降临"。
  • 与主线交汇点：① 两人共同创伤 = 感情合法性的根基（替代血缘的"同类相认"）；② 宋霆"被救过一次"的身世 = 他"隐忍、报恩、不敢越界"性格的逻辑来源；③ 南久童年创伤（[第59章]补叙：被后妈使唤带弟、压到小凯手指遭迁怒、从此贴床沿睡）解释她对"家"的执念与对宋霆的迁怒。
  • 进度：核心已收束，但有若干痛点细节仍开放。
  • 相关伏笔：V3（荒道缘由→[第4章]回收）、V16（身世→[第34章]回收）、V52/V53（少年伤痛/被救→[第34章]回收）、V28（歪脖子树下宋母撑伞，未回收）、V31（读过书的那条巷子，未回收）、V38（红房子，未回收）、V39（手臂拐杖痕，未回收）、V70（"我爸是刑侦队长"半真半假，未回收）。
  • 续写抓手：宋霆旧居红房子[第14章]、读过书的那条巷子[第11章]是现成的"未开启的回乡/寻根"戏眼。

S6 · 婚恋副线（暗恋 / 追求 / 相亲）

定位：市井群像的"情感陪衬"，反复用"外人的婚恋"反衬主线的不可得；同时是"家庭社会压力"的具体化。

  • 起（[第5章]）：柳茵给南久化妆、托她搅黄宋霆的相亲；南久盛装现身、以"新婶婶"行拆台之实[第5章]。
  • 承（[第6章]→[第16章]）：周妍家提入赘式条件（随母姓、备婚房），宋霆一句"算了吧，不麻烦了"婉拒[第6章]；[第10章]柳茵已婚、坦言当年表白被"一个红包"堵回，暗恋线收场；[第16章]李崇光出差归来帮工、追求意图浮出水面（"你有男朋友了吗"[第16章]）。
