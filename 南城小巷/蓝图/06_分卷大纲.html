二、各卷详细大纲

卷一 · 初一（第1-2章｜2.5%）

  • 核心事件：后妈生子 → 南久被父送去亲妈家受冷遇 → 只身百里投奔爷爷 → 荒道遇修车的宋霆、获送归并高烧住院 → 落脚帽儿茶馆、被爷爷指认为"名义叔侄"（[第1章]）；入住后从摆茶点学起，与宋霆建立"叔侄式"日常默契（[第2章]）。
  • 目标：南久要一个能落脚的地方；爷爷要安顿孙女、顺带教她"茶馆的门道"。
  • 结果：南久在茶馆站住脚（"帽儿茶馆在帽儿巷的地位就如旧时的祠堂"[第1章]）；与宋霆的"叔"关系确立。
  • 关键转折：[第1章] 被指定为"名义叔侄"——全书一切伦理障碍的起点（伏笔 V2，[第68章]回收）。
  • 因果链：南振东后妈生子忘女 → 南久被当累赘送走 → 只身寻爷爷 → 荒道遇宋霆（他为何在此？埋 V3）→ 宋霆送归、守夜 → 爷爷收拾偏房收留 → 埋下"叫宋叔"的错位关系。
  • 高潮章：[第1章]（荒道相遇 + 安顿，★3）。
  • 卷尾钩子：南久来了许久"一声没叫过叔"——这段错位关系悬着（[第2章]末）。

卷二 · 高二（第3-7章｜6.4%）

  • 核心事件：南振东把叛逆的南久送回茶馆、与宋霆时隔四年重逢（[第3章]）；当街爆发骂尽委屈、宋霆带她吃夜宵、坦白"那年我开车是出去找你的"（[第4章]）；柳茵托她搅黄宋霆相亲（[第5章]）；得知宋霆身世（父杀母），愧疚请罪（[第6章]）；临别赠电脑、递桂花糕指尖相触、倒视镜对视（[第7章]）。
  • 目标：南久要"被在意"；宋霆要"稳住她、替爷爷兜着她"。
  • 结果：关系从对立破冰，第一次说心里话；感情线由"叔侄"暗渡到"暧昧"的第一次质变。
  • 关键转折：[第4章] 破冰（"那年我开车是出去找你的"——[第1章]伏笔 V1/V3 首次回收）；[第7章] 指尖相触+倒视镜对视（感情线"带电"起点）。
  • 因果链：高二被父送回 → 四年后重逢"认得出" → 南久当街爆发 → 宋霆不还嘴、带她吃饭 → 她说出"被当累赘"的心声 → 得知身世愧疚 → 临别赠电脑（[第8章]证明实为宋霆出钱）→ 对视相触（埋 V20）。
  • 高潮章：[第4章]（当街骂+被兜住，★4）、[第7章]（倒视镜对视，★4）。
  • 卷尾钩子：南久"没再犹豫"地离开南城——她与他将走向何方？（[第7章]末）

卷三 · 大二（第8-26章｜29.0%）

本卷是全书体量最大的"暧昧慢火"卷，内部可再分三小段：

3-1 茶馆日常与暧昧升级（第8-16章）

  • 核心事件：第一次正经喊"宋叔"、识破电脑是宋霆所买（[第8章]）；揪逃单客显管账天赋、接茶挨打手心（[第9章]）；柳茵暗恋线收场、提议茶馆上平台（[第10章]）；机车穿巷吃鸭头（[第11章]）；南乔宇盯梢被镇住、宋霆明确护她（[第12章]）；拆穿假洋人李玮（[第13章]）；品茶如品人、夜走宋霆旧居红房子（[第14章]）；背醉酒的她回馆、衔咬下唇出血、"我会注意分寸"（[第15章]）；私打"提成"、廊窗点香无声守护（[第16章]）。
  • 关键转折：[第15章] 首次身体越界 + 明确退回"分寸"——感情线最强推拉与全书首个 ★5 名场面；[第12章] 宋霆由"中立者"转为明确护她（埋 V34"披着砒霜的糖"）。

3-2 茶山之夏与初定情（第17-26章）

  • 核心事件：首次上茶山、初见珍敏与茶山群像（[第17章]）；隔门板说"我在你身上能看见小时候的我"（[第18章]）；下地干活第一次吃醋（[第19章]）；教桑丫跳舞、军子掉沟（[第20章]）；雨夜余震、芹婶讲他"跟茶树过日子"（[第21章]）；彻夜寻人、砸锁破门（[第22章]）；集市珍敏被朱家撕衣、南久用板砖掩护自己被抓（[第23章]）；锁茅草屋磨尖木棍自救、抛"我爸是刑侦队长"（[第24章]）；20岁生日木屋"我后悔了"、越界共度初夜（[第25章]）；南久主动划界、收起金镯子（[第26章]）。
  • 目标：南久要"被选中"的确定感（"20岁生日那天不再是一个人过"[第22章]）；宋霆要在"恩义"与"私情"间自持。
  • 结果：越界为亲密关系，却被南久主动限缩进"不见天光"的阴影。
  • 关键转折：[第25章] 由"名义叔侄辈"越界为亲密关系——主线关系质变的定义性事件；[第26章] 主动划界，埋下"关系不能见光"的长线矛盾。
  • 因果链：茶山同行 → 珍敏出现激出南久的"比较心/醋意" → 朱家旧债找上门 → 南久为救珍敏被掳 → 宋霆疯狂赴险救人 → 生死劫后的20岁生日 → 木屋越界定情 → 南久冷静划界、藏起金镯子。
  • 高潮章：[第15章]（★5）、[第23章]（★5）、[第24章]（★5）、[第18章]/[第25章]（★4）。
  • 卷尾钩子：南老爷子"一码归一码，你替她出学费不合适"——对二人关系的隐约警觉（[第26章]末，伏笔 V76，[第39章]回收）。

卷四 · 大三（第27-29章｜3.8%）

  • 核心事件：开学送站、宋霆偷塞银行卡（[第27章]）；庇护被传"包养"的夏嫣然、十一宋霆到校门口等她（[第28章]）；南久主动疏远"别来学校找我了"，转身办成个人首场大型快闪舞蹈活动（[第29章]）。
  • 目标：南久要在世俗审视里守住自己的名声与前途；宋霆要"克制地陪着她"。
  • 结果：关系降至冰点、双方"清醒地"收手；南久事业线第一次独立起跳，进入林颂耀视野。
  • 关键转折：[第29章] 南久主动断联（"包养"两字咽回）——主线由"暧昧"转向"克制期"的转折章，也是女主"事业优先"价值观的确立章。
  • 因果链：校园流言刺痛 → 南久不肯为一次心动困于世俗 → 主动疏远 → 把全部力气投进事业 → 拿下个人首场大型活动 → 被林颂耀审视（事业线/男二线起点，埋 V78/V81）。
  • 高潮章：[第29章]（断联 + 快闪引爆中庭，★3）。
  • 卷尾钩子：林颂耀望着那抹忙碌利落的身影、神情渐渐松弛——二人关系走向待定（[第29章]末）。

卷五 · 大四（第30-34章｜6.9%）

  • 核心事件：毕业季"无家可归"、宋霆守着茶馆与三花猫（[第30章]）；返乡住酒店、三花猫"小九"引出宋霆隐秘心绪、柳茵离婚回巷（[第31章]）；借猫喻人、溪边半抱、柳家提亲（[第32章]）；民宿误会、相亲试探、越过界限开房（[第33章]）；夹巷相拥被柳茵撞破、坦白"我们不可能在一起"、茶堂夜谈（[第34章]）。
  • 目标：南久要"趁年轻去外面闯一闯"；宋霆守茶馆与茶山（"只要南老在、茶馆开，他便不会离开"[第34章]）。
  • 结果：亲密关系被第三者坐实，同时"安稳定居 vs 外出闯荡"的分歧浮出水面。
  • 关键转折：[第34章] 确认实质亲密 + 直面"不可能"的宿命（"他给得起的安稳，不是她此刻想要的风景"）——全书分离宿命的定调章。
  • 因果链：毕业无家可归 → 返乡重逢疏离中暗涌 → 三花猫/借猫喻人激出推拉 → 柳家提亲施压 → 越过界限 → 被柳茵撞破 → 坦白"不可能" → 分离宿命悬起。
  • 高潮章：[第33章]（咬吻标记+开房，★4）、[第34章]（夹巷撞破+茶堂夜谈，★4）。
  • 卷尾钩子：宋霆"给得起的安稳，不是她此刻想要的风景"——二人分离的宿命悬起（[第34章]末）。

卷六 · 进入社会（第35-36章｜2.2%）

  • 核心事件：离巷返酆市、为星耀合伙人席位与林颂耀博弈、拒绝30万捷径（[第35章]）；为30万四处碰壁（亲妈家受辱、后妈以彩礼相待），向宋霆开口获无条件相助，ATM前发现卡里原有十万（[第36章]）。
  • 目标：南久要"站稳脚跟的机会"（不是证明自己）；宋霆要"不束缚她、悄悄托底"。
  • 结果：南久获得创业起步的资本，立誓自立；与原生家庭彻底割裂。
  • 关键转折：[第36章] "我打到那张卡里"+ 发现暗藏十万——感情线在"无言相助"中升温的定义性事件，也是女主"自立主线"的起点（伏笔 V95，[第70章]回收）。
  • 因果链：冲击合伙人席位 → 30万门槛 → 四处筹钱受辱 → 向宋霆开口 → 无条件相助 → 发现旧卡十万 → 立誓"由自己主宰人生"。
  • 高潮章：[第36章]（"我打到那张卡里"+ATM发现十万，★4）。
  • 卷尾钩子：初雪中握拳立誓"拼尽全力去赢得一个未来"——事业与人生新起点（[第36章]末）。

卷七 · 人生旅途（第37-55章｜28.1%，正文完）

本卷是全书冲突最密集、高潮最多的重轴卷，可再分四小段：

7-1 契约婚姻与返乡撞破（第37-41章）

  • 核心事件：熬成星耀"铁三角"、林颂耀以经营权为筹码提契约婚姻（[第37章]）；返乡贺寿、巷口剖白、咬唇一吻（[第38章]）；爷孙撞破私情、杖责宋霆、逐南久（[第39章]）；爷爷"以后没事就不要回来了"、携林颂耀返乡见家长（[第40章]）；宋霆与林颂耀饭桌暗锋、爷爷谈婚事（[第41章]）。
  • 关键转折：[第37章] 契约婚姻提议（埋 V96，[第53章]回收）；[第39章] 撞破驱逐——家族线总爆发、主线由"秘密"转为"被斩断"的转折。

7-2 反目与决裂（第42章）

  • 核心事件：歪脖子树下林颂耀强吻南久、当众羞辱，南久反目；夜奔茶馆，宋霆破戒后说"以后不要再见面了"。
  • 关键转折：[第42章] "以后不要再见面了"——主线决裂式转折（伏笔 V111，[第47章]回收）；林颂耀掌握秘密（伏笔 V113，[第54章]回收）。
  • 高潮章：[第42章]（★5）。

7-3 茶山主事与生死重逢（第43-52章）

  • 核心事件：宋霆失联、茶山生乱，南久赶回主事、被珍敏认作"宋老板爱人"（[第43章]）；彻夜推算抢采方案、惊闻宋霆车祸、悟"止损比赢更重要"（[第44章]）；拍板"与天争"抢采、立军令状（[第45章]）；赴黑石洼村借工、得知宋霆当年为她挨打的真相（[第46章]）；宋霆车祸濒死获救、独身赶回茶山、雨后相拥（[第47章]）；雨夜木屋"婚姻之问"、再度越界（[第48章]）；来电声中强行占有、南久反问"你什么时候爱上我"（[第49章]）；以手机待办清单温柔摊牌、划星耀红线（[第50章]）；钥匙试探、现钱抢采平怨、许诺带桑丫出山（[第51章]）；谈大黄之死后痛哭、宋霆撕协议备避孕药放她走（[第52章]）。
  • 关键转折：[第47章] 生死重逢击碎"不再见面"的决心（伏笔 V111 回收）；[第52章] 宋霆主动放手成全——感情线由"纠缠"转向"成人式成全"的转折。
  • 高潮章：[第47章]（车祸赴死/雨中相拥，★5）、[第48章]（"桥归桥路归路"，★5）、[第49章]（"你什么时候爱上我"，★5）、[第52章]（痛哭/放手，★5）。

7-4 退场与反杀（第53-55章）

  • 核心事件：领证当日民政局掉头、以股权文件与林家把柄反将林颂耀（[第53章]）；林颂耀率审计队突袭星耀、南久以律师团与人墙逼退（[第54章]）；签股权转让、应下"离开酆市"、带全部行囊回帽儿巷（[第55章]，正文完）。
  • 关键转折：[第53章] 民政局掉头——婚姻交易线破裂的转折（伏笔 V96 回收）；[第55章] 体面退场、回归南城（埋 V146，[第70章]回收）。
  • 卷尾钩子：南久带全部行囊逆光站在茶馆门前"老板，这么早打烊了？"→ 宋霆缓缓回头（[第55章]末）。

卷八 · 番外（第56-70章｜21.1%）

本卷为"回收—兑现—圆满"卷，可再分三段：

8-1 回馆同居与半公开（第56-61章）

  • 核心事件：回馆住下、面对被扔的旧床、打地铺（[第56章]）；宋霆重买新床、自陈十九岁一见钟情（[第57章]）；看房饭局当众承认"男朋友"、揭"怀孕"乌龙（[第58章]）；额头吻定情、音乐节门票（[第59章]）；同游音乐节、卡丁车赌约、当众接吻（[第60章]）；当众兑现"当爷面表白"的赌约（[第61章]）。
  • 关键转折：[第59章] 额头吻定情（关系由"暧昧"转为"郑重确认"）。

8-2 婚事受阻与长辈默许（第62-67章）

  • 核心事件：南城看房组局（[第62章]）；爷爷单独审宋霆、南久撞见姚洁纠缠（[第63章]）；登门茶叶店"亮明身份"、与爷爷长谈获默许（[第64章]）；主动求婚"我们结婚吧"（[第65章]）；提议领证被拒、说动宋霆接桑丫出山（[第66-67章]）。
