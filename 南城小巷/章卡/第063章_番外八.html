第63章 番外八

  • 字数：4085
  • 一句话剧情：爷爷单独审宋霆；南久撞见姚洁纠缠宋霆，吃醋负气。
  • 本章事件：
    • 吴婶撞破后，南老爷子将宋霆叫入房间，直问"小久那婚没结成，是你撺掇的？" → 宋霆毫不迟疑承认，并表明"我想娶南久"；老爷子只答"过完中秋再说"。
    • 两人出屋后神情如常、各自忙去，吴婶却因外人撞破私事而提心吊胆、心不在焉 → 清晨之事被压下，南久始终不知情。
    • 南久中午进茶堂，吴婶反常欲言又止；她去厨房见宋霆在收拾罗氏虾，两人贴额、陪拣虾子般亲昵 → 宋霆仍带笑不提清晨之事。
    • 中午南久要出门看房，宋霆自二楼廊窗叫住、主动提出"我带你过去" → 两人并肩看手机，吴婶看在眼里，问爷爷"他们差了有一轮吧"，爷爷答"差八岁"。
    • 晚上南久与夏嫣然通话沟通走访情况；宋霆去老街茶叶店久未归，南久外出溜达 → 在巷口撞见店员姚洁拉住宋霆胳膊、吐露"我其实……从三年前就……"，南久眼底结霜、决然离去。
    • 宋霆甩开姚洁、斥"好自为之，别把饭碗砸了"，随即电话质问小张（谁告诉他"我是一个人"、调店如何沟通） → 命小张把姚洁叫回店、妥善处理。
    • 南久负气疾行，宋霆追上在巷中无声拉扯，最终一把将她扛上肩带回帽儿巷 → 南久又气又羞，挣扎数落一路。
    • 至茶馆门口被南老爷子撞见，南久半真半假告状"他在外面玩女人" → 老爷子反将一军"准许你在外面玩男人，不许他在外面玩女人？"，挥手"要吵上楼吵去"，并唤宋霆"泡杯降火茶"；宋霆将南久拉上楼。
  • 登场人物：南久、宋霆、南老爷子、吴婶、姚洁★、小张（电话中，姚洁口中称"张哥"）、夏嫣然（电话中）
  • 人物动态：
    • ① 时间推进：撞破当日（清晨对质）→ 当晚。
    • ② 身份/处境变化：宋霆向爷爷挑明"我想娶南久"，被以"过完中秋再说"暂缓；姚洁被调离老街店、次日报到城北店；南久与宋霆的关系遇上姚洁这一外部冲击。
    • ③ 心境/能力变化：南久第一次为宋霆"失控"吃醋（与她自以为的云淡风轻判然有别）；宋霆因南久的在意而"得偿所愿"。
  • 伏笔：埋：爷爷"过完中秋再说" → 为二人婚事设下时限/条件；埋：姚洁"从三年前就……"（话未说完）→ 埋她的心思与去留；埋：小张一句"你不是一直单着吗" → 埋宋霆在南城生意圈"单身"形象与其私下恋情的信息差。收：吴婶清晨撞见宋霆从南久房出 [呼应第62章]——引出爷爷对宋霆的当面对质；宋霆"我想娶南久"承接此前二人的感情定局 [呼应第59章]。
  • 秘密·信息流动：宋霆向爷爷承认搅黄南久的婚事、表明想娶她；清晨撞破一事始终瞒着南久（她不知爷爷已知情）；姚洁三年心思被宋霆当场点破并划清界限；宋霆的"单身"人设因小张而被戳破。
  • 人物关系变动：宋霆↔南老爷子：由晚辈/堂倌走向"求娶孙女"的对质与默许（过完中秋再说）；南久↔宋霆：甜蜜期遭姚洁事件冲击，南久吃醋、宋霆借势箍紧；宋霆↔姚洁：以调店划清界限、斥其"好自为之"；宋霆↔小张：上下级间的追责；南久↔南老爷子：爷爷在玩笑中表露对两人的偏向。
  • 情绪设计：基调：虐（★3）、甜（★2）、谐（★1）；名场面：南久在巷口撞见姚洁拉住宋霆、眼底结霜转身离去（★3）；宋霆当街将南久扛上肩带回帽儿巷（★3）
  • 章末钩子：南久半真半假告状"他在外面玩女人"，爷爷反将一军"准许你在外面玩男人，不许他在外面玩女人？"并唤宋霆"泡杯降火茶"，宋霆把南久拉上楼"看你还嘴不嘴硬" → 引出第64章次日饮食日常与南久登门茶叶店。
  • 线索归属：番外线、感情线、家族线（爷爷的态度）、群像（姚洁、小张）
  • 写作手法：反差（南久自以为云淡风轻却情绪失控、"每一句气话都像裹着蜜"）；悬念钩子（姚洁"从三年前就……"被截断）
