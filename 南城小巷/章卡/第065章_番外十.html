第65章 番外十

  • 字数：2855
  • 一句话剧情：南久向宋霆"摊牌"示好；夜半消失惊悸，主动求婚。
  • 本章事件：
    • 与爷爷说开后南久有了底气，溜上楼欲告知宋霆 → 撞见宋霆刚洗完澡、"猛男出浴"，她反锁门、靠语言与姿态主动贴近。
    • 南久以爷爷的话为引（"他让我……对你好点"），在正午主动与宋霆亲近 → 白日、正午的坦荡欢愉（"他从未想过，在白日、甚至正午，灵魂竟能挣脱一切束缚"）。
    • 宋霆下楼，吴婶问"你不是一般不睡午觉吗"，他答"起得太早，补个觉"；南久下楼"像只骄傲的孔雀"，被宋霆攥住手腕，她挑衅"去、找、男、人、灭、火" → 宋霆二十分钟通话后又把她拽上楼，整个下午未出阁楼。
    • 临关门前两人一前一后下楼，吴婶诧异"这一大下午怎么都没见人"，南久一本正经"在上面探讨工作的" → 宋霆瞧她脸不红心不跳，嘴角勾起嘲弄的笑意。
    • 夜里宋霆忙工作，看着熟睡的南久生出"从此君王不早朝"的感受；深夜躺下后，睡意中向身旁探手，摸到一片冰凉虚空 → 他惊醒、心脏下坠（"那夜她决然离去时，心脏被生生撕扯开的痛楚，再一次……席卷重来"），掀毯下楼、拨打南久电话。
    • 茶堂黑暗里响起手机铃声，南久蜷在厨房门口、盯着手机回头，解释"渴醒了，下来喝口水" → 宋霆攥住她的手把她拉回阁楼，翻身紧拥，一声极轻的叹息落在她发间。
    • 次日南久出门签夏嫣然的租赁合同，回来发现阁楼多了台崭新饮水机；宋霆说"省得你半夜跑下楼" → 南久笑意更深，从背后环住他的腰，说"我们……结婚吧！"
  • 登场人物：南久、宋霆、吴婶、南老爷子（提及）、夏嫣然（提及）
  • 人物动态：
    • ① 时间推进：与爷爷说开当日（正午）→ 当夜 → 次日。
    • ② 身份/处境变化：南久以"我们结婚吧"主动推进婚事；宋霆以添置饮水机回应其对"消失"的惊悸。
    • ③ 心境/能力变化：南久获爷爷默许后"登时有了底气"、白日主动；宋霆的占有与不安（夜半失控惊悸）被放大，转而以生活细节留住她。
  • 伏笔：埋：宋霆夜半摸空后的惊悸（"那夜她决然离去"的旧痛）→ 埋他对失去南久的深层恐惧；埋：阁楼添置饮水机（"省得你半夜跑下楼"）→ 以物写其不安与守护；埋：南久"我们……结婚吧" → 引出后文婚事推进。收：南久"跟爷爷摊牌"的底气在本章兑现为向宋霆示好并主动提婚 [呼应第64章]。
  • 秘密·信息流动：南久把"爷爷默许"转达给宋霆；宋霆将夜半惊悸藏起（不明说，只以饮水机回应）；对外以南久"探讨工作"的说辞遮掩。
  • 人物关系变动：南久↔宋霆：关系由同住日常推进到"结婚"提议，占有欲与失而复得的惊惧并现；南久↔吴婶：日常遮掩与打趣；南久↔南老爷子：默许被转达、成为她主动的底气。
  • 情绪设计：基调：甜（★3）、虐（★1）；名场面：南久自背后环住宋霆的腰说"我们……结婚吧！"（★4）；宋霆夜半摸到虚空惊坐、循铃声寻到下楼喝水的南久（★3）
  • 章末钩子：南久从背后环住宋霆的腰提出"我们……结婚吧！" → 为番外后段（婚事/结局）埋下引子。
  • 线索归属：番外线、感情线
  • 写作手法：以物写人（饮水机写宋霆的不安与守护）；留白（"沉默的背影如同一扇在她面前关上的门，门后是无人得见的狼藉"）
  • 金句：「我们……结婚吧！」「他虽然不是纣王，却在此刻，真切地体会到了几分"从此君王不早朝"的滋味。」「省得你半夜跑下楼。」
  • CP互动：南久×宋霆：阁楼正午的主动示好、楼下"去找男人灭火"的挑衅与二十分钟通话后的"拽上楼"、整个下午的阁楼厮磨、夜半惊悸后的紧拥、次日的求婚。
  • 视角标注：第三人称有限视角；南久、宋霆双视角，含吴婶侧写。
