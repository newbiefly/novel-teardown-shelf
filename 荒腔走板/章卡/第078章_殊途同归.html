第78章 殊途同归

  • 字数：5788
  • 一句话剧情：工寨对峙，周幸自曝弃仇为苍生，齐煊获亡妻遗诏起志。
  • 本章事件：
    1. 因赵执劫子既为威胁齐煊也为邀约周幸 → 周幸负弓率众追至驿站，面对东西两辆一模一样的马车，凭"插旗"细节异样（袁察见旗、萧涉川未见）择追无旗那辆，追至废弃工寨。
    2. 因工寨后院锁房疑关小世子 → 周幸正欲下令，陆酌光察觉李言归率大队人马逼近，遂令燕决等四人进去救人得手即走、以黑羽为哨，自己与陆酌光去前院"赴约"。
    3. 因赵执只带李言归入寨 → 陆酌光缠绸布备杀，唤赵执"义父"；周幸暗处骤射一箭直取赵执心口，被李言归斩断，周幸现身楼阁与赵执隔空对峙。
    4. 因赵执要那封遗诏 → 赵执给周幸两条路：交出东西他助其为父翻案；否则死在此地。周幸自曝"赫连筠已死在塞外大火，我只是周幸"，翻案卷宗是假、从未想翻案。
    5. 因周幸追述塞北一路所见（守驴老人、十室九空、民不聊生） → 揭示她所求"不过是让大齐百姓活着"，与赵执"国土收复、大齐一统"殊途同归却立场相异。
    6. 因齐煊枯坐一日终下决心 → 他藏起卷宗束发净面静等早朝办王妃后事，摸到郑欣枕下第二封信：忏悔监视、望其振志救江山救民生。
  • 登场人物：周幸、陆酌光、钱不断、燕决、萧涉川、袁察★、赵执、李言归、赫连钦（追述）、守驴老人★（追述）、许奉（提及）、崔慧（追述）、齐煊、郑欣（第二封信）
  • 人物动态：
    • 年龄时间：紧接77章傍晚至入夜；追述赵执十八岁入京初见赫连钦、周幸离塞北后一路见闻。
    • 身份处境：周幸正式当面向赵执割裂"赫连筠"身份，自认"周幸"；齐煊读第二封信后彻底坚定起兵之志。
    • 心境能力：周幸展露超越复仇的家国悲悯格局；赵执首次自陈"国土收复、让边疆百姓像人一样活着"的真实抱负，反派动机复杂化；齐煊从撕裂到决绝。
  • 伏笔·埋：
    1. 周幸呼吸紊乱、身体本能失态被陆酌光敏锐察觉——周幸身体隐疾/命数伏笔。
    2. 两辆马车"插旗"矛盾——袁察见旗、萧涉川未见旗的诡异（暗示有人视觉异常或另有玄机）。
    3. 赵执反复提"快六月了，你不打算回来一趟"——陆酌光六月异虫苏醒/需回赵府的命数伏笔延续。
    4. 陆酌光缠绸布备大开杀戒——前院血战预告（第79章收）。
    5. 郑欣第二封信"望君振志千万次，救江山救民生"——齐煊起兵正当性与情感支撑伏笔。
  • 伏笔·收：
    1. 陆酌光"看看枕下"提醒 [呼应第77章] 本章齐煊摸出郑欣第二封忏悔信，反转第一封诅咒信的绝望。
    2. 卷宗是"翻案证据" [呼应第77章] 本章周幸对崔慧追述中揭破：吕鸿供词是假、无法二次提审、时隔太远无凭据，翻案本就不可能。
    3. 赵执与赫连钦渊源 [呼应第76章赵执说周幸"与你父亲太过相像"] 本章追述赵执十八岁初见赫连钦"那一眼悲悯深入骨髓"的往事。
    4. 郸玉山匪不敢犯、许奉施粥救难民 [呼应前文郸玉篇] 本章点明周幸最终留在郸玉的缘由。
  • 秘密·信息流动：
    • 周幸向赵执（及读者）揭破：翻案卷宗是假、她从未想为父翻案、赫连筠已"死"、真正所求是苍生活命。
    • 赵执向周幸自陈真实抱负（国土收复大齐一统），双方摊牌各自终极目的。
    • 周幸对崔慧的旧对话首次公开其"不为翻案"的真心（此前对崔慧亦半藏）。
    • 郑欣第二封信向齐煊袒露：她本是父命监视的耳目，多年目睹其善行而自省忏悔——秘密临终解开。
    • 遗诏下落成赵执此行核心目标（他推断齐煊敢放手一搏必因遗诏在周幸手中）。
  • 谜题/线索：
    • 揭秘：翻案卷宗是假证据，周幸真实动机是"让百姓活着"而非复仇。

    • 谜面：那封遗诏究竟在何处、是否真在周幸手中？

  • 阵营动态：
    • 赵执亲率大队府兵＋无常司（李言归）设局工寨，欲围杀周幸夺遗诏。
    • 周幸一方分兵：燕决等四人救小世子，周幸陆酌光赴约拖住赵执。

    • 赵执反派动机被赋予家国理想，与周幸形成"殊途同归、立场相异"的镜像。
  • CP互动：陆酌光唯一察觉周幸追车时呼吸紊乱的失态并低声关切"怎么？"，读懂她掌控不住的身体本能；周幸脱口否决分头行动（不愿与陆酌光分开）；关键时刻二人默契配合赴约对峙赵执。
