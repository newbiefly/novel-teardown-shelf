人物设定集·配角

归纳自人物台账 + CP互动台账 + 关系台账 + 章卡（第2-100章，全书已拆完）。
主角（周幸、陆酌光）见《04_人物设定集_主角》，本篇只写配角。
分级：重点配角详卡（主+辅标签+反差点）／次要角色简卡（一句话性格）／龙套省略。
性格标签均从行为拆出，带 [第X章] 佐证；人名用原文用字。

一、重点配角详卡

齐煊（岭王 / 前东宫太子）

  • 身份：大齐皇室宗亲，岭王（曾为东宫太子，十二年前东宫事变后被贬"岭南王"），许奉的学生，赫连钦冤案与皇位真相的核心相关人。全书查案—夺位主线的第二主角。
  • 性格：
    • 主标签｜护师护民的暴烈赤子：恩师许奉被杀，护师心切一触即炸，两次暴怒险些当场抓人 [第2章]；查案数日无果疲累至极仍不肯放手 [第9/12章]；岭南施粥救济落难的袁察，善政七年后仍有回响 [第8章]。心是热的，情绪外露，与工于城府的赵执、陆酌光形成反差。
    • 辅标签①｜隐忍待时的夺位者：由避祸游王转向主动逼宫夺位，庙中枯坐一夜求见荣国公未果 [第50章]；冷静数点京中各方兵力、锁定荣国公禁军为关键变数 [第50章]；皇城惊变中新君归位 [第98章]。
    • 辅标签②｜藏痛于物的孤父：随身携带幼子齐凌所雕木雕小马（情感寄托）[第12章]；私藏东宫太子时期的木雕、被幼子看破"藏起来偶尔看就是喜欢""盼爹不再哭泣" [第50章]。
    • 反差点：对苍生慈悲、对恩师赤诚（暴烈护短） vs 对夺位大业能压下私怒、步步为营（隐忍谋断）；表面"无权无能的小王爷" vs 内里胸怀东宫壮志的储君。
  • 欲望动机：为恩师许奉伸冤 → 查赫连钦冤案真相 → 夺回本属于自己的皇位（先帝遗诏传位齐煊，被叔父齐宥篡夺）。
  • 与主角关系：与周幸从各查各案到结盟共谋夺位，商议由陆酌光亲手斩仇人龚泽为周幸报父仇 [第98章]；是周幸复仇与自身夺位的最大同盟。
  • 关键行动：护师暴怒险抓人 [第2章]；"赵大人"一句身份压服赵恪 [第8章]；义庄守灵回忆师恩 [第12章]；庙中求见荣国公、算清各方兵力定夺位决心 [第50章]；以"随波逐流安身、坚守本心立命"点醒崔慧 [第50章]；递剑助陆酌光斩龚泽 [第98章]；新君归位 [第98章]。
  • 阵营：皇室宗亲 / 查案—夺位主导方（与周幸联盟）。

赵执（当朝首辅）

  • 身份：大齐当朝首辅，赵恪之父，陆酌光（陆敛）义父，"无常司"缔造者。全书反派主脑。妻吕乡音（近亲所生智症）。
  • 性格：
    • 主标签｜隐在幕后的操盘手：早年为异族侯王赫连钦门客，反手效仿其暗卫模式豢养死士建"无常司"黑白两部 [第15/21章]；构陷赫连钦"战败投敌"枭首满门 [第34章]；三十年冤案、金矿案、大运河贪腐皆有其手 [第50/34章]。做事不亲自沾手，靠棋子与把柄操控满朝——裹挟兵部尚书郑瑈（私售官盐）、要挟崔慧（陆驰名单）[第50章]。
    • 辅标签①｜睚眦必报的清算者：金矿案被停职后复职即下杀令清剿周幸 [第15章]；丧子（赵恪死）后不哀反谋、冷静策划反击 [第21章之后]。
    • 辅标签②｜留一线余地的丈夫：对近亲畸病的妻子吕乡音临死仍留其活路 [第99章]——反派身上唯一的人性缝隙。
  • 欲望动机：把持朝纲、铲除一切威胁（周幸/赫连旧案知情者）、维系与齐宥"收复国土"的旧誓与既得权柄。
  • 与主角关系：周幸的杀父灭门仇敌（构陷赫连钦）与陆酌光的义父兼囚主（以巫毒吊命之药控制陆敛）；被周幸亲手所杀 [第99章]。
  • 关键行动：赫连门客反建无常司 [第15/21章]；构陷赫连钦满门抄斩 [第34章]；下杀令清剿周幸 [第15章]；以陆驰名单要挟崔慧 [第50章]；临死留妻吕乡音活路 [第99章]；被周幸诛杀 [第99章]。
  • 阵营：朝廷权臣 / 反派核心（与皇帝齐宥共谋冤案）。

崔慧（都察院官员 → 倒戈）

  • 身份：出身寒门，都察院官员、左都御史龚泽亲信，后被贬翰林院七品编修。查案小组名义成员，实则另有使命。
  • 性格：
    • 主标签｜律法为尺的持重者：言必称"大齐律法"，持重守规 [第2章]；此行真实目的是查赵家在郸玉隐瞒什么，冷静布局派暗卫夜探赵恪寝房取金石 [第12章]——外表守规、内里有谋。
    • 辅标签｜信仰崩塌后求"立命"的抉择者：被赵执以"陆驰冤案"名单要挟，得知恩师龚泽三十年前疑曾徇私舞弊，信仰崩塌；向齐煊倾诉"为官求安身还是求立命" [第50章]；最终在安身与立命间选择本心。
    • 反差点：循规蹈矩的律法信徒 vs 敢暗探首辅之子寝房、敢在要挟下背离恩师阵营的破局者。
  • 欲望动机：查明赵家在郸玉隐瞒的真相 → 在"安身（随波逐流）"与"立命（坚守本心）"间做出选择。
  • 与主角关系：与周幸方从各自查案到目标趋同的间接盟友；受齐煊"安身立命"点拨而定志向。
  • 关键行动：以"大齐律法"持重查案 [第2章]；派暗卫夜探赵恪寝房取金石 [第12章]；被赵执以陆驰名单要挟 [第50章]；向齐煊倾诉抉择困惑 [第50章]；掌殿试卷、钓局设宴套秦焕自曝赫连冤死内幕 [第50/73章]。
  • 阵营：都察院 / 第三方势力（龚泽亲信）→ 抉择后倒向查案伸冤一方。

李言归（无常司黑部 / 悲情）

  • 身份：无常司黑部成员（持半块黑色玉牌），赵恪侍卫头领出身，陆酌光身边的得力干将，曾竞争令主之位输给郑颖。
  • 性格：
    • 主标签｜忠诚干练的冷面杀手：赵恪属下时忠诚干练、先行调查卷宗 [第2章]；无常司黑部干将，办事利落 [第17章]；被赵恪派去截杀崔慧 [第17章]。
    • 辅标签｜市井气的抠门年轻人：半夜找陆酌光借钱讨媳妇 [第17章]；被陆酌光就"如何讨回被占的便宜"求教（帮陆参谋感情事）[第47章]——冷血身份下藏着接地气的烟火气。
    • 反差点：自幼残酷训练的黑部杀手（冷面办脏活） vs 借钱讨媳妇、给人出感情主意的抠门青年（市井温度）。
  • 欲望动机：早期效忠陆酌光/无常司体系 → 随陆酌光倒戈后转向助周幸方；竞令主失败后的失落与去向。
  • 与主角关系：陆酌光的贴身副手与倾诉对象（陆多次向他袒露心迹，如"没受美人计蛊惑""如今选择是心之所向" [第84章]）；随陆倒向周幸阵营，收留误认陆为仇人的窦二娘之孙、揭其知恩人真相 [第85章]。
  • 关键行动：先行调查许奉案卷宗 [第2章]；把脉确认陆酌光身体特殊、猜到刺客是周幸 [第17章]；被派截杀崔慧 [第17章]；替陆参谋感情 [第47章]；竞令主输给郑颖 [第45/47章]；收留窦二娘之孙 [第85章]。
  • 阵营：无常司黑部（赵执势力）→ 随陆酌光倒向周幸。

袁察（千路山大当家 / 忠仆）

  • 身份：千路山大当家（非原贼寇，七年前岭南寻亲落难受齐煊施粥之恩后落脚为匪），雪晴、月明之兄，赫连钦旧部一脉（青鹰部关联）。周幸阵营核心武力。
  • 性格：
    • 主标签｜有恩必报的义匪：外表壮硕威猛虎目锐利，实则礼节周到、谈吐大方，颠覆山匪预期 [第8章]；七年前受齐煊施粥之恩，由衷敬佩、有恩必报 [第8章]。
    • 辅标签①｜嫉恶如仇的直性子：当众怒骂陆酌光"认贼作父、连狗不如、当悬梁赎罪" [第50章]；被吕鸿冒犯即拍桌大怒 [第8章]——藏不住恨意，眼里揉不得沙。
    • 辅标签②｜牵挂老母的孝子：连夜转移老母避赵恪追查 [第50章]；熬夜探母归来报母亲近况 [第50章]。
    • 反差点：占山为王、拧断胸骨的悍匪（威猛狠厉） vs 待恩人执礼、为老母提心吊胆的孝义之人（周到柔软）。
  • 欲望动机：报齐煊施粥之恩 → 追随周幸为赫连钦（旧主一脉）复仇雪冤 → 护住老母与妹弟。
  • 与主角关系：周幸最可靠的武力与忠仆之一（担心其死"影响周幸心绪"被陆酌光点破 [第54章]）；揭破周幸颈上玉竹项链装着爹娘骨灰 [第54章]。
  • 关键行动：岭南受恩、拍桌怒斥赵恪 [第8章]；承认山有神仙散并每年巡山销毁 [第8章]；踹断严寿胸骨 [第22/36章]；怒斥折鸟对峙陆酌光 [第50章]；揭玉竹藏骨灰 [第54章]；率青鹰部假扮难民入京、皇城惊变夺城门 [第53/97章]。
  • 阵营：周幸阵营核心武力（赫连钦旧部一脉）。

陶缨（风月楼老鸨 / 忠仆）

  • 身份：郸玉风月楼（青楼）老鸨，原为青衣戏旦，与周幸交好、隐属周幸统领的隐秘组织。
  • 性格：
    • 主标签｜历尽风尘的消息通：青楼经营者，八面结交，第一个爆出许奉常来听曲+运河贪腐醉话的关键线索 [第4章]；看人极准，旁议"周幸喜欢陆秀才" [第55章]。
    • 辅标签｜舍身护主的忠仆：赵恪将其押来当众胁迫、逼陆酌光射杀，命悬一线仍是周幸阵营一员 [第23/24章]。
    • 反差点：逢场作戏、见惯世情的风尘老鸨（世故) vs 甘做棋子被押上刑场也不叛主的忠仆（赤诚）。
  • 欲望动机：追随周幸（少主），以青楼为据点供给情报、掩护行动。
  • 与主角关系：周幸的忠仆与情报眼线；被赵恪押作要挟周幸的人质 [第23/24章]。
  • 关键行动：爆料许奉听曲+运河贪腐醉话 [第4章]；被赵恪押来当众胁迫 [第23/24章]；旁议点破周幸对陆酌光的心意 [第55章]。
  • 阵营：周幸阵营（隐秘组织成员）。

吴吉安（文喜 / 掌印太监·内线）

  • 身份：大齐掌印太监，本名文喜，随身携国玺，御工监名匠太监武福的徒弟。守先帝遗诏一脉的关键人物。
  • 性格：
    • 主标签｜藏锋守诺的深宫棋手：身居掌印太监高位、随身携国玺 [第45章]；向齐宥进谏裁减军匠、召民间匠人，看似进言实为布局 [第45章]；用迷香逼疯篡位者齐宥 [第99/98章]——在皇帝身边下最深的一步棋。
    • 辅标签｜承师遗志的守诺人：师父武福受托守先帝遗诏、誓死救恩人许奉被酷刑折磨致死 [第97/100章]；文喜承其衣钵，卸任后收小徒小靥传下去 [第100章]。
    • 反差点：伺候篡位昏君、随侍君侧的近侍（顺从） vs 暗中守遗诏、亲手迷疯皇帝助新君归位的倒戈者（谋逆）。
  • 欲望动机：承师父武福遗志守护先帝遗诏 → 助真正的储君齐煊归位、还赫连冤案公道。
  • 与主角关系：周幸—齐煊夺位一方的深宫内线；师承守遗诏一脉，与许奉、武福同为这条暗线的牺牲/传承者。
  • 关键行动：进谏裁军匠召民间匠人、送票拟 [第45章]；迷香逼疯齐宥 [第98/99章]；卸任收小靥为徒传衣钵 [第100章]。
  • 阵营：皇帝近侍（明） / 守遗诏一脉·周幸齐煊系统（暗）。

齐宥（宥王 / 篡位昏君）

  • 身份：大齐皇帝，齐煊的叔父（先帝之弟），年过半百旧疾缠身。全书朝廷层面的最高反派。
  • 性格：
    • 主标签｜心虚护党的篡位者：皇位来路不正（先帝遗诏本传齐煊，齐宥篡夺、散布"先帝越三子传弟"谣言）[第21/98章]；明知蹊跷仍保赵执 [第21章]；知情并压制赫连钦冤案 [第21章]——靠遮掩与结党维系不正的皇权。
    • 辅标签｜困于旧誓的病君：与赵执有年轻时"收复国土"的共同誓言，被这段旧誓与既得利益捆绑 [第21章]。
    • 反差点：高踞龙椅的一国之君（至尊) vs 皇位得来不正、终被迷香逼疯、定"篡位反贼"之名被废的失位者（虚弱可悲）。
  • 欲望动机：保住篡夺来的皇位 → 压制赫连冤案与遗诏真相、庇护共谋的赵执。
  • 与主角关系：周幸（赫连冤案）与齐煊（夺位）共同的朝廷对手；被吴吉安迷香逼疯、皇城惊变中被废 [第98章]。
  • 关键行动：篡位散谣 [第21/98章]；明知蹊跷仍保赵执、压制赫连冤案 [第21章]；被吴吉安迷香逼疯、被废定"篡位反贼"之名 [第98章]。
  • 阵营：朝廷 / 反派（篡位昏君，与赵执共谋冤案）。

樊蔚（松公子 / 常松，荣国公长孙 / 情敌）

  • 身份：荣国公樊仲卓长孙，二十六岁，亲兵卫/锦衣卫，化名"松公子/常松"。周幸的暗线盟友兼感情线情敌。
  • 性格：
    • 主标签｜风流周旋的贵公子暗线：与周幸相识数年、暗中联络查大运河贪腐 [第45章]；助周幸抓云宗鸣、挂靠赃船 [第45章]——纨绔皮相下是查贪腐的实干盟友。
    • 辅标签｜情深难得的追求者：赠周幸玉竹簪（后为白莲簪）示好，是陆酌光吃醋的源头 [第45/100章]；出狱后向陆酌光索还白莲簪 [第100章]，情意不减。
    • 反差点：出身荣国公府、看似逢场作戏的松公子（轻佻) vs 为查贪腐甘做暗线、被家族弃卒保帅下狱仍不改初衷的实干者（深沉）。
  • 欲望动机：查大运河贪腐 → 追求周幸（未果）→ 在家族利益（交兵权）与自身立场间挣扎。
  • 与主角关系：周幸的多年暗线盟友+感情线情敌（陆酌光因他数次吃醋 [第45/74/100章]）；被荣国公故意扣京、下狱，家族借其逼交兵权 [第45章之后]。
  • 关键行动：暗中联络周幸查贪腐 [第45章]；赠玉竹/白莲簪示好 [第45章]；助抓云宗鸣挂靠赃船 [第45章]；被家族弃卒保帅下狱 [第45章之后]；出狱向陆酌光索还白莲簪 [第100章]。
  • 阵营：荣国公府 / 周幸暗线盟友（情敌线）。

隗谷雨（鬼医仵作）

  • 身份：七十多岁道医仵作，打一辈子光棍，耳背脾气古怪，莫惊秋（唯一徒弟）之师。周幸阵营核心成员，全书探案的"技术担当"。
  • 性格：
