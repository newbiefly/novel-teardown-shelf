单元06 第25-30章 训女·秦氏发威·搬家·宋柯提水·毒计·寿筵

边界：第25-30章。收尾判据——第30章末寿筵开场后曹决心报复（心理决意=自然钩子），第31章「桃汁」同一宴席实施阴谋（动手=新事件起点，归入下一单元）。

  • 字数：16217（25章3653 / 26章2157 / 27章1973 / 28章2663 / 29章3161 / 30章2610）
  • 一句话剧情：秦氏雷霆整顿（揭发曹传谣·搬出罗雪坞），宋柯井边提水二人联想前世，曹设毒计谋害香兰+寿筵伺机报复。
  • 本章事件（因果链）：
    1. 王氏训林东绫不许追宋柯 → 林长敏暴怒打林东绫一耳光"我已给你相好了人家"→ 王氏哭+溺爱安慰送衣料 [第25章]
    2. 曹丽环与赵月婵密谋搬拢翠居(近卧云院/林锦亭) → 赵识破意图但未拒 → 秦氏突然到场 [第26章]
    3. 秦氏当场揭发曹指使卉儿散布"曹与林锦亭"假流言（吴三家的/冯双家的/思巧三个帮凶指证）→ 卉儿扛罪"与旁人无关"→ 秦氏命赵月婵啐曹、韩妈妈打曹耳光 → 卉儿脱裤打三十板（在小厮面前·毁名声）→ 思巧被赶到曹丽环处当差 [第26-27章]
    4. 秦氏命曹搬出罗雪坞到府后西侧旧屋(降级) → 韩妈妈清点罗雪坞家具（防曹偷拿）[第28章]
    5. 香兰照顾受伤的思巧（涂药+劝慰）→ 思巧心中对香兰复杂（感激+嫉妒+负疚）[第28章]
    6. 宋柯井边提水：香兰打水遇宋柯 → 宋柯微笑如前世萧杭新婚夜 → 香兰一怔水桶掉入井中 → 宋柯帮提水送回 → 两人各自联想前世（宋柯明确回忆"前世病入膏肓时妻子沈氏的眼睛"→ 确认宋柯=前世萧杭）[第28章]
    7. 四顺儿★（曹的奶娘之子/猥琐色棍）在院门口纠缠香兰 → 香兰厉声斥退 [第29章]
    8. 四顺儿向曹求"把香兰许配给我"→ 曹设毒计：暗示要用香兰笼络四顺儿（把香兰许配猥琐汉，既除心腹之患又笼络奴才）→ 思巧在屏风后偷听到全部阴谋 [第29章]
    9. 秦氏寿辰设宴 → 多家权贵官眷到场争说林家小姐亲事（周氏/段氏等）→ 曹被全场无视、未获引见 → 新仇旧恨，决心报复 [第30章]
    10. 寿筵上思巧★（新来曹处）心绪不宁、欲言又止——她已知毒计但未告诉香兰 [第30章]
  • 登场人物：陈香兰、曹丽环、卉儿、怀蕊、秦氏、赵月婵、王氏、林长敏★、林东绫、林东绮、林东绣、宋柯、刘婆子、韩妈妈★、红笺★、思巧★、四顺儿★、吴三家的★、冯双家的★、素菊、钱妈妈★
