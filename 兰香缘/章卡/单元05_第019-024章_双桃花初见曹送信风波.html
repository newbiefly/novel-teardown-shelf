单元05 第19-24章 双桃花初见·曹送信风波·秦氏定策

边界：第19-24章。收尾判据——第24章末秦氏定策（让香兰盯曹+亭三爷搬走+暗中试探宋柯）+林东绮被断念想（事件闭环）｜第25章「训女」另起二房训女新场景｜字数19057偏大但事件完整性强（双桃花初见→曹送信→秦氏对策为一条完整链），不宜拆开。

  • 字数：19057（19章3130 / 20章2516 / 21章2853 / 22章3415 / 23章3585 / 24章3558）
  • 一句话剧情：香兰簪花初遇林锦楼+补荷包结交宋柯，曹丽环送信谋赖林锦亭被香兰化解，秦氏定策断林东绮念想。
  • 本章事件（因果链）：
    1. 茶会第二幕：林锦亭+宋柯到场 → 林东绮/绣/绫争相讨好宋柯（拉拢宋檀钗）→ 宋柯与香兰目光相撞，香兰一惊低头 [第19章]
    2. 曹丽环看宋柯/林锦亭方向"脸潮红双眼冒光"（疑对林锦亭动心）[第19章]
    3. 香兰簪花遇林锦楼：香兰搬花途中偷摘玉兰簪发、以湖为镜哼《西厢》→ 林锦楼醉酒后园散步偶见，惊艳呆住、口干舌燥 → 香兰觉出灼热目光不适、闻其身上酒气脂粉香 → 小厮吉祥来报李二爷强逼翠云破身，林锦楼被叫走，香兰趁机逃走 [第19-20章]
    4. 香兰首遇宋柯：宋柯在竹林拦住香兰、借擦衣摆脏污扣下帕子 → 又以"母亲做的荷包破了"为由请香兰补 → 约定大后天巳时取荷包，不待香兰推辞便走人 [第20章]
    5. 林东绣+林东绫小姐们争宋柯的心思浮出水面：绮(嫡女·暗中筹划)+绣(庶出·精明算计)+绫(嫡女二房·热烈直接) 各怀心思 → 宋檀钗察觉林东绮意图、故意配合透露宋柯不急成亲等信息 [第21章]
    6. 香兰赴约还荷包 → 宋柯送翠玉小青蛙 → 用帕子和白绢花交换、二人约见数次 → 香兰得知宋柯名字、开始有几分好感（联想前世萧杭的风采）[第22章]
    7. 曹丽环与卉儿密谋（疑欲赖上林锦亭）→ 差香兰送信给林锦亭（信中表面是诗词·实为钓鱼第一步）→ 怀蕊跟踪 [第23章]
    8. 香兰识破曹意图 → 把信交给素菊（林锦亭房里人）并暗示"此事不妥、我心向林家"→ 素菊听不懂 → 宋柯恰好出来，香兰转向宋柯说明情况 → 宋柯当即承诺转告王氏 [第23章]
    9. 宋柯拿信去找王氏 → 王氏找秦氏 → 秦氏定策：让香兰盯曹+让林锦亭搬去与宋柯同住+暗示宋柯"少逛园子多读书" [第24章]
    10. 秦氏暗中试探宋柯对林家小姐的态度 → 宋柯"脸色微变旋即微笑"表明心迹 → 秦氏评价"太过老练油滑，绮姐儿耍不过"→ 命林东绮偷听后，当面断其念想："断了这个念想"→ 林东绮哭了一宿 [第24章]
  • 登场人物：陈香兰、林锦楼、宋柯、林锦亭、曹丽环、卉儿、怀蕊、林东绮、林东绣、林东绫、宋檀钗、秦氏、王氏、素菊★、寒枝★(林东绣丫鬟)、吉祥★(林锦楼小厮)、卷华★(宋檀钗丫鬟)、踏莎★(林东绮丫鬟)
  • 人物动态：
    • 香兰：首次正面遇林锦楼（被动·警惕）+ 与宋柯从陌生到多次交往（渐生好感）→ 化解曹送信危机（主动保护林家·展现智谋）[第19-23章]
    • 林锦楼：醉酒偶见香兰簪花 → 惊艳心动（从画圈标记到正面被吸引）[第19-20章]
    • 宋柯：主动接近香兰（借帕子→补荷包→送玉蛙→还绢花）→ 多次约见 → 在送信事件中迅速帮香兰解围 → 被秦氏暗中试探（"心思太深"）[第20-24章]
    • 曹丽环：从炫耀到密谋——茶会被挤兑后转向谋赖林锦亭（差香兰送信+散布流言）[第19-23章]
    • 林东绮：暗中筹划嫁宋柯（通过拉拢宋檀钗）→ 偷听秦氏试探 → 被母亲当面断念想、哭一宿 [第21-24章]
    • 林东绣：精明算计（分析宋家利弊·认为宋柯"瘦死骆驼比马大"）→ 暗中竞争 [第21章]
    • 林东绫：热烈直接追宋柯、与林东绣暂时结盟挤兑曹 [第21章]
    • 宋檀钗：察觉林东绮意图、故意配合透露宋柯信息（有脑子有主意）[第21章]
  • 伏笔：
    • 埋：林锦楼纳良妾芙蓉时"芙蓉被歹人奸杀至今悬案"(第13章已埋) → 本单元林锦楼身上酒气脂粉香+小厮报李二爷强逼翠云，暗示林锦楼出入风月的生活方式 [第19-20章]
    • 埋：宋柯送香兰翠玉小青蛙（物件伏线·二桃花信物加深）[第22章]
    • 埋：曹丽环与卉儿密谋"已按姑娘说的办了"——除送信外还有别的布局？[第22-23章]
    • 埋：曹丽环内心独白揭示真实意图：嫌弃任羽无能→想赖上林锦亭做妾→"正头奶奶的位子迟早是我的"[第22章]
    • 埋：秦氏评宋柯"太过老练油滑、野心大"——暗示宋柯未来可能与林家冲突？[第24章]
    • 收：宋柯捡绢花 → 本单元用绢花与香兰交换帕子（物件闭环）[第22章，回收第14章F13]
  • 秘密·信息流动：
    • 贯穿性：香兰重生身份不变
    • 单元内：
      • 曹送信意图=曹+卉儿知 → 香兰识破并告知宋柯→宋柯告知王氏→王氏告知秦氏（信息从暗到明，逐层上报）[第23-24章]
      • 秦氏暗中试探宋柯+"心思太深"评价 → 秦氏+林东绮独知（宋柯不知被评价）[第24章]
      • 林东绮对宋柯的心思 → 被母亲看透并公开断掉（从秘密变为母女共知）[第24章]
      • 宋柯对香兰的多次接近（补荷包/送玉蛙/还花）→ 目前只有香兰+宋柯+读者知 [第20-22章]
      • 林锦楼对香兰的心动 → 林锦楼+读者知，香兰只觉不适未认定 [第19-20章]
  • 人物关系变动：
    • 香兰↔林锦楼：首次正面接触（他惊艳心动、她警惕闪避）
    • 香兰↔宋柯：从陌生到多次交往（帕子→荷包→玉蛙→绢花），香兰联想前世萧杭有几分好感
    • 宋柯↔林东绮/绣/绫：三位小姐暗中竞争、宋柯游刃有余
    • 秦氏→宋柯：评价"老练油滑野心大"、不欲为婿
    • 秦氏→林东绮：断念想（母女裂痕？）
    • 香兰↔秦氏(间接)：秦氏命人让香兰盯曹（香兰进入秦氏视野、获信任）
