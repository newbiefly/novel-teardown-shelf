01 故事概要

作品信息

  • 书名：缺口
  • 作者：码代码的Gigi
  • 章数：77章
  • 字数：约28.3万字
  • 题材：都市现实日常 + 言情甜宠（双题材混合）

一句话故事（logline）

豪门之子江恒被父亲设局陷害入罪，为保护妻子陈昭而伪装出轨、逼她离婚；陈昭查明真相后倾力救他，两人跨越"信任"的裂痕破镜重圆。

题材标签

都市言情 / 追妻火葬场 / 破镜重圆 / 豪门恩怨 / 双时间线 / 假出轨 / 先婚后爱（过去线是恋爱→婚姻）

情感基调

克制、隐忍、留白；大情绪藏在日常细节里（离婚场面平静如水，痛在细节）；甜（过去线）与虐（现在线）双线交织，苦中带暖，终归圆满。

核心矛盾

  • 要什么：江恒要保护陈昭不受江家权斗牵连（怕她一起沉船/为他坐牢煎熬）→ 陈昭要的是"相互信任、共同面对"而非被单方面保护。
  • 谁挡：① 反派江亚洲（江恒之父）设医保骗保局陷害江恒，是外部大boss；② 江恒自身"自以为为她好、替她做决定"的自私/不信任，是内部核心障碍。
  • 怎么升级：江恒假出轨离婚（保护）→ 陈昭痛苦离婚 → 江恒逼宫父亲失败被送进去 → 陈昭查明真相主动救他 → 江恒被放出却"配不上"不敢复合 → 摊牌点破"信任"障碍 → 江恒自省坦诚 → 复合、信任重建、圆满。

核心创意/卖点

  1. "假出轨"的反转设计：男主的"出轨/渣"全是保护女主的伪装，真相是被父亲设局陷害入罪——把"追妻火葬场"的火，烧在一个"其实无辜且深情"的男主身上，虐感与反转张力拉满。
  2. 双时间线交织：过去线（多伦多留学甜蜜相恋）与现在线（婚后离婚追妻）穿插，用同一物象（面/戒指/圣诞树/番茄藤）跨线缝合，今昔甜与痛的对照极具后劲。
  3. "信任"而非"原谅"的和解内核：区别于普通追妻文"男主受苦→女主心软原谅"，本书点破真正的障碍是"信任重建"——女主要的不是保护，是共同面对；把"为你好式的爱"当成需要反思的自私来写。

一句话主题/故事内核

真正的爱不是"我替你做决定、为你好"，而是"相互信任、共同面对危机"——书名"缺口"即江恒内心的情感缺口（不被爱、被当工具、习惯一个人），只有陈昭能填满；而填满它的前提是他学会信任与坦诚，不再以"保护"之名剥夺她共担的权利。[第69章][第76章][第77章]

爽点/泪点公式

  • 泪点公式（核心）：深情男主隐忍受苦（假出轨/坐牢）→ 女主被蒙在鼓里痛苦决绝 → 真相揭开（原来他一直深爱且为她牺牲）→ 女主心疼倾力相助 → 意难平后破镜重圆。（"误会式虐恋 + 真相反转 + 双向奔赴"）
  • 爽点公式（辅）：女主隐藏富家女/能力强（谈判/理财/救人）→ 关键时刻决断力爆表（"他毁我就毁他儿子"）→ 主导救出男主，反客为主。
  • 甜点公式（过去线）：隐富男主 × 通透女主，异国相遇 → 英雄救美/日常照顾 → 番茄藤/烂糊面式的以物传情 → 双向奔赴的初恋甜。

卖点标签组合（商业视角）

  • 题材标签：都市豪门追妻火葬场 + 破镜重圆 + 双时间线
  • 人设标签：
    • 女主：隐藏富家女 × 通透决断的"清醒恋爱脑"（打工攒钱不占便宜、离婚净身出户不贪、救夫时狠辣有担当）
    • 男主：深情隐忍的"缺口男"× 假出轨的"伪渣真痴"（心狠手辣的商业强人 vs 对妻子极致占有与守护、内心有情感缺口）

文案/开篇钩子类型

  • 好奇钩（主）：楔子——女主平静飞去温哥华当面撞破丈夫"出轨"、冷静提离婚，丈夫却只认不辩、抓她手腕问"你不想问什么吗"——反常的"出轨"制造巨大悬念（他为何不辩解？）。
  • 情绪钩（辅）：女主克制到极致的痛（点评外室妆容转移痛苦、深夜等丈夫两小时提离婚），代入感与意难平。
  • 开篇即抛"看似狗血出轨、实则大有隐情"的谜面，勾读者追真相。

核心梗 + 创新点

  • 核心梗：假出轨/为爱放手（男主主动做恶人逼女主离开以保护她）+ 追妻火葬场 + 豪门设局。
  • 创新点（旧元素新组合）：
    1. 把"假出轨"的动机从常见的"绝症/身世"换成"父亲设医保骗保局陷害入罪"，落到都市商战/豪门权斗的真实肌理，比狗血更有说服力。
    2. 用双时间线让"曾经多相爱"与"现在多痛"实时对照，放大虐感。
    3. 和解内核从"原谅"升级为"信任重建"，女主不是被动原谅的圣母，而是主导救人、并要求平等信任的清醒者——对"为你好式的爱"做批判性反思，比传统追妻文有深度。
  • 生命周期判断：追妻火葬场/破镜重圆是长青梗，"假出轨保护"稍显套路但仍有市场；本书的差异化在"双线缝合的文学质感"和"信任内核"，是可借鉴的微创新方向。
