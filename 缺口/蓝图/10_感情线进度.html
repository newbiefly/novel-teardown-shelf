10 · 感情线进度

归纳来源：CP互动台账（77 章逐章）。CP = 陈昭 × 江恒。本书感情是绝对主线，双时间线本质是"同一段感情的因（过去线）与果（现在线）"。每条带 [第X章] 锚点。

一、感情线双轨结构总览

过去线（因）：相遇 → 暧昧 → 主动错过 → 重逢回暖 → 定情 → 圆满 → 回国结婚
                                    ↓（六年后）
现在线（果）：撞破出轨·离婚 → 跪求被拒 → 查真相 → 真相揭开 → 救人 → 追妻火葬场 → 复合 → 信任重建 → 圆满
  • 过去线回答"他们怎么相爱、江恒的缺口从哪来"；现在线回答"缺口如何被填满"。
  • 书名"缺口" = 江恒内心的情感缺口，只有陈昭能填满（[第46/57/77章] 三次点题）。

四、追妻火葬场机制（本书精髓·可复用）

  1. 障碍从"误会"升级为"信任"：真相揭开（[第53章]）后，复合的障碍不再是"是否原谅出轨"，而是"能否再毫无保留信任你"（[第69章]）——把火葬场的核心从"洗清冤屈"提升到"关系本质"，格调更高。
  2. 女主主导救人 = 火葬场的前置反转：[第64-67章] 陈昭主动救江恒，让"追妻"变成"双向奔赴"——不是男主单方面追，而是女主先救了他、再由他证明配得上。
  3. 男主的火葬场功课不是下跪，是"自省 + 坦诚"：江恒的转变经 江婕点破（[第72章]"这笔账你算得过来吗"）→ 自省 → 坦诚剖白（[第73章]）→ 承诺（[第74章]），是"认知升级"而非"卑微讨好"。
  4. 锯齿状拉扯拉满张力：[第67-74章] 呈"障碍—暧昧—摊牌—松动"反复 4 轮，每轮靠近就被信任障碍推开，把复合的甜熬到最浓。
  5. 复合分两步走："试试"考察式复合（[第75章]）→ 信任重建真圆满（[第76-77章]）——不一步到位，留出"重建信任是漫长过程"的余地（邓叔点题）。

五、核心矛盾与情感内核

  • 核心矛盾：江恒"自以为为她好、替她做决定"的自私（不信任她能共同面对） vs 陈昭要的"相互信任、共同面对"。这个矛盾双线同构：过去线 [第43章]"是不是对我好该我自己判断"已埋，现在线假出轨是同一错误的极致放大。
  • 缺口母题：江恒的情感缺口（被抛弃恐惧、给不了幸福的自卑）源于原生家庭（[第9/16/19章]），只有陈昭的"无条件相信与陪伴"能填满（[第46/57/77章]）。
  • 续写红线：① 假出轨必须是"真爱式放手"非真渣；② 复合障碍必须落在"信任"而非"原谅"；③ 救人必须女主主导；④ 复合要"考察式两步走"，不可一句道歉就大团圆。
