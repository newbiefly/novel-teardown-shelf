2. 性格标签（从行为拆出）

  • 主标签：外柔内刚的谋略型闺秀——礼数周全、言语温和，骨子里却有宁折不弯的刚烈与步步为营的算计。
    • 行为佐证：碧云庵以利相诱、主动谋划，与危险人物周旋[第10/12章]；识破傅家毒计拼死求生[第14章]；被父掌掴仍倔强抗争[第128章]；被逼绝境"我不做傅家的女儿就是了"[第176章]；以当事人身份当众顶俞阁老、逼供左俊杰[第172–173章]。
  • 辅标签一：绵里藏针的操盘手（以柔克刚）——出手绵软、一击致命，善借势、善设局。
    • 行为佐证：诈供、推演[第51章]；劝赵凌改"拼死"为"借势"[第54/56章]；设局反制冯氏、以"见颖川侯"反将一军[第86章]；斗唐佩玲"以从容压其锋芒"[第107/109章]；借束妈妈之势敲打俞家[第203章]。
  • 辅标签二：清醒的断舍离者——对至亲至仇都能亲手切割，不拖泥带水。
    • 行为佐证：对傅家由期待→心寒→死心→恩断，称呼由"父亲"改"老爷"[第163章]、"除了同占'傅'字，再无关系"[第199章]；对俞敬修心结彻底放下[第142章]；对赵凌的犹疑"去意已决"、主动夜访索银[第65/66章]。
  • 反差点：对家人慈悲（护丫鬟、疼幼子、悯旧仆、为外家奔走） × 对仇敌狠厉（强睁眼逼供、当众决裂、共谋复仇）；以及一身闺阁礼数 × 临危当众编谎、拔剑摊牌的强悍——她是最守规矩的闺秀，也是最敢破规矩的执棋者。

3. 人物弧光（一句话）

从任人摆布、被家族当"死人"处置的华阴九小姐，变成能亲手执棋反杀、撑起一府门面、与丈夫并肩复仇的三品命妇。

5. 人物弧光总结

九小姐 → "死人" → 逃亡者 → 掌事者 → 主母 → 命妇 → 复仇共谋者。 傅庭筠的一生是一条"被人安排→自己执棋"的上升线：开篇她被家族当弃子"处死"，中段她学会以利相诱、以柔克刚、当众编谎，后段她敢顶父兄、斗情敌、审宿仇、布局复仇。她始终守着一件事——"死也要清白"[第17章]，并在守住清白之上，长出了"能依靠的只有自己"的骨头[第93章]。

6. 关键抉择时刻（定义这个人）

  1. 识破毒计、拼死求生[第14章]——家族要在庵中"就地处死"她，她不再隐忍退让，选择搏命。这是她"刚烈"人格的第一次出场。
  2. 认母许婚、越过父兄之辱嫁赵凌[第141章]——父兄百般羞辱、赵凌受耳光，她仍昂首跨越，接过母亲授的庚帖。她第一次亲手为自己的命运做决定，且是逆父权而为。
  3. 当众与生父决裂［"我不做傅家的女儿就是了"］[第176章] / 当街恩断［"除了同占'傅'字，再无关系"］[第199章]——不是一时意气，而是看透傅家"只求权势、重俞家颜面"后的理性切割。
  4. 强睁眼看逼供、直面"父命杀己"真相[第172–173章]——由"不敢看血"到强睁眼，心性向"敢直面酷烈"转变；她不再逃避父母对她的冷酷真相。
  5. 坦诚交心、共谋复仇[第274章]——以柔克刚、以情逼真言，明大义，既参与复仇又劝其"有分寸"。她与赵凌从此是真正意义上的"同谋"。

表演要点 / 续写红线：写傅庭筠时语速不急、句子稳，先算人心再动情；受辱时先忍、忍到临界才一次性爆发（掌掴后的倔强、母丧后的守礼）；对幼子、旧仆、姊妹语气软，对仇敌话术凌厉而留三分体面（"礼貌足够"[第197章]）。红线：①不可写成毫无主见、坐等拯救的柔弱女主——她全书都在"自己执棋"（诈供、设局、布局皆出她手）；②不可写成冷血无情的复仇机器——她对慈母、幼子、旧仆的柔软是其底色。

2. 性格标签（从行为拆出）

  • 主标签：深藏不露的谋略型枭雄——外谨内断、借势而为、谋定后动，冷硬之下深藏家仇。
    • 行为佐证：碧云庵以点穴、翻墙无声的功夫周旋而不肯多言己身[第8章]；对十六爷以"家学三脚猫功夫"搪塞、不肯当场表态投军[第36章]；主动"借势"、善用陌毅/鲁成之关系造势，谋略形象确立[第72章]；借皇上"飞鸟尽良弓藏"之虑藏锋[第153章]。
  • 辅标签一：铁石心肠却守良善（恩义型首领）——手段狠绝，却对部曲、对傅庭筠守底线。
    • 行为佐证：为救傅庭筠与部众起争执仍决意留下[第15章]；为保全众人决意独自面对陌毅[第48章]；对旧部"愿同生共死"[第48章]；疑为暗杀冯大虎者（狠绝）[第100章]。
  • 辅标签二：蛰伏的复仇执念者——复仇是驱动他往上走的第一引擎，且以"活受罪"为宗旨。
    • 行为佐证：为妻受辱结怨西平侯·冯家[第233章]；暗查西安证据、幕后布局扳倒俞家[第276/310章]；第274章向傅庭筠坦白复仇决心而克制；第314章"隐于幕后、以'活受罪'为复仇宗旨"。
  • 反差点一：对外冷静持重、寡言内敛 × 对内（傅庭筠）贪恋黏人、"食髓知味"、少年气——初识时"内敛沉稳"与成婚后"热情黏人"判若两人[第148/151章]。
  • 反差点二：自认"两个注定南辕北辙的人"的克制退让[第66章]×关键处比谁都果决的担当（跪地提亲、受耳光不还手、拔刀镇场 [第140/141章]`）。

3. 人物弧光（一句话）

从身负家仇、藏身逃亡、连姓名都不敢说的寒微孤客，变成有从龙之功、能运筹朝局复仇的权臣，也终成能让妻子安稳持家、把家安在"她所在之处"的丈夫。

5. 人物弧光总结

逃亡孤客 → 总旗/百户 → 从龙之臣（正三品）→ 贵州总兵/都督佥事 → 幕后执棋的复仇者 → 丈夫与父亲。 赵凌的成长由两条线拧成：一是身份翻盘线（从见不得光的亡命者，到赐字"虎臣"的宠臣）；二是复仇执念线（为父母家仇、为妻子受辱，从被动受制走到主动布局）。他的冷硬外壳下有两处柔软——对旧部的恩义（"愿同生共死"）和对傅庭筠的痴守（"愿得一人心"）。

6. 关键抉择时刻（定义这个人）

  1. 为救傅庭筠与部众起争执、仍决意留下[第15章]——利益与义气冲突时，他选了人。"铁石心肠却仍守良善"的自证。
  2. 为保全众人决意独自面对陌毅[第48章]——宁愿自己涉险，也要保住傅庭筠与旧部。他身上"以己为盾"的担当底色。
  3. 为护妻拔刀镇场、又守晚辈之礼[第141章]（并受傅五老爷耳光不还手 [第140章]）——极致的"能屈能伸"：对外敢拔刀，对岳家守礼数。他懂得"什么时候该硬、什么时候该忍"。
  4. 向傅庭筠坦白复仇、并听其劝守住"分寸"[第274章]——他把最隐秘的执念交给妻子，也接受她的约束。从"独自扛"到"与她共谋"的转折。
  5. 以"活受罪"为复仇宗旨[第314章]——复仇完成时，他选择的不是取命而是让对方活受罪。冷硬之下仍有他自己的一套"分寸"。

表演要点 / 续写红线：写赵凌时少言、决断，答话常只给结论不给过程（"我有分寸"）；情绪藏在动作里（赠头巾、夜访、狂奔百里的焦灼、成婚后的黏人）。对傅庭筠可由冷转热、忽而少年气，对官场与仇敌则全程冷静克制。红线：①不可写成恋爱脑的工具人男主——他全书是"自己布局、自己扛"的行动主体（借势、征战、复仇皆出他手）；②不可写成没有软肋的冷面枭雄——他对傅庭筠的痴守与"食髓知味"的少年气是他的反差萌点。
