卷一·横塘镇宅（第1-23章｜22.5%）

阶段目标

  • 女主目标：以"被接回镇宅尽孝"为伪装，潜伏查出母亲冤案真相；在谢家立住脚、不被嫡脉拿捏。
  • 谢家目标：议定姑娘们的亲事（清和、清如、清圆），攀附更好的门第。

核心事件（按序）

  1. 立身与示弱：清圆回府一月，穿堂煎药示孝被冷遇[第1章]；被清如纵婢泼湿、不告状反揽过，借湿衣博老太太给淡月轩添人手[第2-3章]。
  2. 查案启动：托月鉴调回母旧仆陶嬷嬷结盟[第4章]→ 陶嬷嬷回溯冤案始末，清圆推断"一石二鸟"（最得宠者一死一逐，背后有人动手脚）[第5章]。
  3. 宅斗排雷：以"青梅"之名设局试探三房，排除莲姨娘、锁定扈夫人[第10-12章]；查得关键人证小丫头被送升州后"病死"、其家骤富[第7章]。
  4. 感情线起点：春日宴上清和相看李观灵[第6-8章]；清圆被蹴球砸中，初遇丹阳侯三公子李从心[第9章]。
  5. 外力与压力：谢纾实为停职查办归家[第13-14章]；蒋氏作梗坏清如婚事[第15-17章]；李从心赠酥、清如拍翻酥盒失仪[第15章]；清圆识破眼线小喜却留而用之[第16章]。
  6. 逼婚与反目：清圆追问父冤情被"人证物证俱在"驳回[第19章]；李从心求娶、侯府托观察使夫人撇清、老太太怒召[第20章]；清如当众掌掴清圆，清圆以退为进自请回陈家[第21章]。
  7. 格局剧变：谢纾由节度使改贬幽州刺史、举家迁幽州[第22章]；清圆回陈家道别、受赠红木妆盒作退路[第23章]。

关键转折与因果链

  • 第12章（暗线转折）：查案锁定扈夫人，但"单凭这点证据完全是以卵击石"→ 埋下"取证/借势"的长期需求，逼出后续"借沈润翻案"的主线走向。
  • 第21章（关系转折）：从"暗中较劲"升级为"当众动手"→ 清圆以退为进测出老太太底线，心念"新仇旧恨一齐算"，由被动忍耐转为主动蓄势。
  • 第22章（环境转折）：谢纾贬谪 → 谢家由"一方大吏"跌为"犯官家眷、受人监管"[第22章]，为全书的"以女换援"、迁幽州遇沈润埋下总因。

卷末钩子（悬念升级）

老太太拉拢清圆随行身边照应，清圆心明"世上没有无缘无故的示好"——她这个半路捡回的孙女"到了发挥作用的时候"[第22章]；同时清圆及笄将至[第23章]、殿前司监管落地[第24章]。由"内宅小斗"升级为"戴罪之身上京场"，舞台随之更换。

卷二·幽州求生（第24-62章｜38.2%）

阶段目标

  • 女主目标：为谢家求援→ 借沈润之势自保 → 逃脱"齐大非偶"婚局与宅斗杀局 → 继续追索母案。
  • 沈润目标：稳住谢家这笔政治账，并逐步对清圆起意、逼近。

核心事件（按序）

  1. 求生开局：举家迁幽州、受殿前司监管造册[第24-25章]；清圆献泥金名册、独自登沈府求见[第25-26章]。
  2. 初会沈润：清圆误认沈润为都使、当面向其陈情，真沈澈归府揭穿[第27章]；沈润冷淡审视、暗中追问其婚配[第27章]。
  3. 旧怨与交易：老太太暗示沈润为良配[第28章]；谢纾登门，沈润点破"剑门关冷遇"旧怨[第28章]；家宴夜沈润醉赠兽面透雕玉佩[第30章]。
  4. 复起：沈润借谢纾之手扳倒政敌付春山，谢纾官复原职[第34章]；沈润显露刑狱手段与"十二灯树"复仇名单[第34章]。
  5. 玉佩纠葛与心迹：护国寺还佩遭拒[第35-36章]；沈府设宴、密室对峙，清圆直言"不给人做妾"[第38-40章]；沈润一箭射落清如胸前玉佩[第41章]。
  6. 险局：碧痕寺芦苇荡遇伏（苦肉计失控，小厮被杀），沈润率殿前司救场[第44章]；被押入殿前司、点破苦肉计、挑明"你是我私事"[第45-46章]。
  7. 提亲与缓兵：李从心当众提亲、扬言回横塘下聘[第49章]；清圆以"父母之命"婉拒，实为缓兵之计[第50章]；宫中选妃口谕至[第51章]。
  8. 求娶明说与选妃：沈润守柜提亲、"我这里正好有个缺"、陪清圆做满母亲七日法事[第52-53章]；诏命清如、清容入宫备选[第54章]。
  9. 宅斗决战（反杀）：沈润借选妃布局令清如落选[第55章]；清圆反撩沈润、共谋处置清如、送胭脂[第57章]；扈夫人护国寺设毒计，清圆将计就计、引清如入局受辱[第58-60章]；清容倒戈、沈润领兵入府护清圆、当众敲打扈夫人[第61章]。
  10. 拿捏：沈润遣严复登门，以买凶证据勒索扈夫人五万两、逼其阻断清圆亲事[第62章]。

关键转折与因果链

  • 第34章（势力转折）：沈润借谢纾除政敌 → 谢家否极泰来，也为"谢家此后仰沈润鼻息、清圆被当筹码"埋因。
  • 第52-53章（感情质变）：沈润由暗中纠缠转为当面求娶、并陪伴做母亲法事 → 清圆"由畏转感"，好感显著升温（"也没说不喜欢"）。
  • 第54章（战场转移）：选妃 → 宅斗由内宅升级到宫闱/内侍省，扈夫人公然违逆老太太，矛盾公开化。
  • 第60章（宅斗高潮）：护国寺毒计反噬其女 → 清圆"以彼之道还施彼身"，清如失贞、进宫路断，扈夫人房声势大跌、众叛亲离[第60-61章]。

卷末钩子（悬念升级）

第62章：扈夫人被严复勒索、被迫变卖产业，且被逼"阻断清圆与丹阳侯家婚事"，她暗下决心"你嫁不成小侯爷，清圆也嫁不成"[第62章]——由"内宅斗狠"转入"对清圆婚事的直接破坏"，引出卷三的议亲/退亲风暴。

卷三·议亲定亲（第63-84章｜21.6%）

阶段目标

  • 女主目标：守诺嫁李从心 → 识破真相后退亲 → 在"依礼求娶"的规矩里夺回主动权。
  • 沈润目标：拆散清圆与李从心、把清圆娶进门；同时为谢家解围以固宠清圆。

核心事件（按序）

  1. 提亲与了断：李从心携丹阳侯夫妇手书回幽州提亲[第63章]；清圆赴上京归还玉佩欲了断，沈润避而不见、以"将与穆家定亲"相激、强拥告白"你别嫁给他，嫁给我成吗"[第64章]；清圆回幽州议定与李从心亲事[第65章]。
  2. 设局拆散：东皋夜宴李从心当众言"她识大体"（沈润设局），清圆寒心[第66章]；谢纾战败获罪[第67章]；清圆晨赴侯府别业撞破李从心私情、当场退亲[第68章]。
  3. 弃女与请旨：谢家求援无门，沈润暗示"救谢家须清圆亲来"，老太太"把人骗过去"[第69章]；沈润留清圆、亮后颈"充"字黥印述连坐之祸[第70章]；清圆怒逐设局的沈润、芳纯一句"大嫂子"泄底[第71章]；清圆套话识破"定亲穆家"实为幌子，沈润殿前请旨指婚、将清圆归置陈家门下[第72章]。
  4. 依礼求娶：清圆一反常态回撩、陈家二老入幽州接走清圆、立"依礼求娶"之规[第73-74章]；沈润登门送聘、过二老关，清圆以纳猫契刁难[第75章]；坦白内情、二人同赴市集聘猫定情[第76章]。
  5. 宣示与备战：游街、鸿雁楼当众宣示娶清圆、回怼谢家[第77章]；赠六万两妆奁、约定石堡城平定后请期[第78章]；谢家知受骗、定下婚宴逼拜之计[第79章]。
  6. 定婚期：沈润殿前震慑诋毁之臣、题"大圆子"寄情[第80章]；初识皓雪、芳纯坠胎[第81章]；蒋氏告密婚宴发难之计、清圆以利结盟二房[第83章]；谢纾班师失势、沈澈因芳纯欲和离、定婚期十一月初六[第84章]。

关键转折与因果链

  • 第68章（感情抉择转折）：撞破李从心私情 → 李从心线终结，清圆"有恃无恐"的局面消失，退婚反而把自己推入更被动之境，只能"求沈润"。
  • 第72章（婚局定盘）：识破幌子 + 沈润请旨指婚 → 婚姻由"交易/算计"落定为"圣旨+真心"，清圆由怨转惜（"全世界辜负她，还有一个沈润不会辜负她"）。
  • 因果主线：沈润"拆李从心—请旨—依礼求娶"三连布局 → 谢家无从插手 → 引出卷四"谢家婚宴发难 vs 圣旨"的正面对撞。

卷末钩子（悬念升级）

第84章：婚期将近，谢家密谋"携户籍册子、婚宴逼拜、叫清圆在贵人圈抬不起头"[第79章]；同时沈家突发**芳纯要与沈澈"和离"**之变[第84章]——大喜前夜，双线危机同时压顶。

卷四·成婚当家（第85-101章｜16.7%）

阶段目标

  • 女主目标：站稳沈家主母之位、执掌中馈、护住妯娌芳纯、清算姚家与谢家旧怨。

核心事件（按序）

  1. 成婚与翻盘：谢老太太率扈夫人闯婚宴、当众质问"无媒无聘"[第85章]；黄门宣旨封清圆"广阳郡夫人"，谢家争无所据、闹婚惨败[第86章]。
  2. 当家与说合：新婚次日设团圆宴说合沈澈、芳纯[第87章]；入宫谢恩、向皇后献策，点破清容"母亲冤案真凶另有其人"[第88章]；布崔婆子为耳目、防皓雪[第89章]；开导芳纯破"纳妾"心结、以"第一碗茶汤"敲打皓雪[第90-91章]。
  3. 回谢府清算：沈润返京、清圆回陈家探祖、拒谢家求和[第92章]；清和、正则登门苦求，清圆松口回谢府探病父[第93章]；谢纾示靳氏龙衔珠遗玉、吐露"撵母是父意"隐情、承认靳氏被冤[第94章]；清圆以妆奁赎回春台、陶嬷嬷[第94-95章]。
  4. 休扈氏：清和得知清如纠缠李观灵，大闹上房[第96章]；谢纾当众写休书休扈夫人、扈氏触柱未死被遣回娘家[第96-97章]；沈润负伤归来、暗查"余孽"[第97章]。
  5. 清算姚家：指挥使府首度大宴、引姚家母女出花厅[第98章]；清圆设局诱皓雪现形，皓雪欲迷奸沈澈反被捉奸[第99章]；沈润押姚家母女入卢龙军大牢[第100章]。
  6. 年节与变起：沈家头一个团圆年、孤独园善政见效[第101章]；大年初一惊闻姚家母女牢中"上吊"一死一伤[第101章]。

关键转折与因果链

  • 第97章（仇怨转折）：扈氏被休、遣回娘家 → 母案仇人第一次落败，且"此景与当年撵靳春晴出府似曾相识"[第97章]，因果循环；扈氏因"夏姨娘、小厮两条人命在身"不敢闹大，为终章行凶埋因。
  • 第99章（外家线转折）：设局捉奸 + 雀儿供出象胆皮滑胎真相 → 姚家（芳纯娘家）图谋彻底破产，芳纯倒向清圆。
  • 因果主线：清圆借沈润之权完成"内宅清算"（休扈氏）+ 掌握姚家案 → 姚家母女入狱 → 为终章"扈氏借狱中伪案反击"提供舞台。

卷末钩子（悬念升级）

第101章：团圆年被命案打断——姚家母女牢中"上吊"，一死一伤，沈润随即陷入"私设刑狱、逼死命官家眷"的绝境[第102章]。危机从"宅斗胜利"骤然翻转为"灭顶之灾"，直接引爆终章。

终章·昭雪（第102章｜1.0%）

核心事件

  1. 反转起点：姚家母女"自尽"经仵作验出麻绳勒痕（他杀），沈润被陷、姚绍入京告御状[第102章]。
  2. 真凶与布局：被休的扈夫人说动卢龙军团练使幼弟扈重宽、贿通狱卒麻三伪造自尽，欲借命案扳倒沈润[第102章]；沈润实为将计就计、以姚家母女为饵诱扈氏出手的"螳螂捕蝉"之局[第102章]。
  3. 朝堂昭雪：谢纾为脱"无故休妻"之罪，当众抖露休妻隐情（主母毒杀妾室、嫁祸另一名妾室）→ 清圆母亲靳春晴的毒杀罪名洗清；沈润奏明真凶落网，仅受"罚俸半年、解职一月"轻罚（实为婚假）[第102章]。
  4. 清算与收官：扈氏一门三人斩立决，清圆携母亲牌位观刑、沉冤得雪，沈润抬手遮住她的眼[第102章]；姚绍贬为蜀地都水使者；清容受封代公主出塞和亲[第102章]。
  5. 感情收束：沈润假称被解职试探，清圆甘愿"同富贵、也可共患难"[第102章]；末句沈润疑清圆有孕，"你不会怀上了吧"戛然收束。

情绪峰值

第102章情绪达全书最高——爽★5、暖★4、反转★4、泪★3；名场面：朝堂昭雪 + 法场观刑、沈润遮眼[第102章]。
