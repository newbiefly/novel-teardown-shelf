05 · 人物设定集 · 主角

本书：猫腻《庆余年》，745 章 / 约 307.4 万字。
数据源：人物台账（205 人）+ 关系台账（795 条）+ CP 分片 + 139 张章卡。
章号一律为全书连续编号。
本篇只写"人物自身怎么变"；两人之间关系怎么变见 07_人物关系网.md。
用法：AI 读完应能"扮演"范闲写对白且不崩人设；续写时以"行为逻辑""崩人设红线"为对照。

外貌/气质补充：猫腻写范闲不堆辞藻，多借旁人眼里立起来——婉儿看他是"少年郎"，庆帝看他是"像她"的複制品，陈萍萍看他是"像小姐"的孩子。写好范闲的关键不是描脸，而是写出那股**"在笑，但眼睛没笑"**的错位感。

1.2 性格内核（从行为拆出，非套模板）

  • 主标签：扮猪吃虎的清醒利己者 + 护崽式深情。
    他永远先装弱、装乖、装蠢（当着皇子自称"微末小臣"），实则步步算计；但一旦触及"自己人"，立刻不计代价——为救范建一党硬顶皇帝 [第642-646章]，为报陈萍萍之仇血洗京都 [第679-694章]。
  • 辅标签一：记仇的"体面派"。
    报仇要"让被打的人知道是我打的" [第73章]，讲究明面立誓、当众打脸（对贺宗纬"名单+毒针当众断肠" [第710章]），而不是暗杀——他要的是**"你知道、天下知道"**的解气。
  • 辅标签二：现代人的怀疑主义。
    "这世上没有值得相信的人"是五竹的告诫，也是范闲骨子里的信条（[第126章]）；他对谁都留一手——连陈萍萍、言冰云都反复怀疑。这既是护身符，也是他痛苦的来源。
  • 反差点（最抓人处）：对苍生的温柔 vs 对仇敌的狠厉。
    一边给素不相识的洪常青报仇、给桑文赎身、给西湖农人过小日子 [第285章][第746章]；一边能对明老太君弑母不眨眼、对言冰云"我不原谅你" [第687章][第393章]。他"心温柔、手段狠"（陈萍萍评语 [第98章] 的反面镜像）。

1.3 价值观 / 软肋

  • 价值观（全书主线母题的承载者）：
    1. "我只站陛下这一边" 只是权宜的生存姿态 [第78章]；真正的内核是叶轻眉碑文——"希望庆国的人民都能成为不羁之民……不向豺虎献媚" [第26章]。范闲一生为母亲复仇的过程，就是从"独善其身的利己者"走向"继承母亲济世意志者"。
    2. "做人做成神仙那样，又不能真的长生不老，感觉一定会很糟糕" [第105章]——他拒绝成神、拒绝被工具化，最终选择退隐西湖而非问鼎。
  • 软肋：
    • "自己人"：范建、婉儿、若若、五竹、陈萍萍、思思——凡涉及他们，他的理智会短路。
    • 母亲：叶轻眉是他一生执念，也让他被庆帝当成"她的複制品"来用。
    • 孤独：他其实极怕孤独（[第580章]"不敢相见"陈萍萍、[第689章]被五竹离弃的梦）。

1.6 行为逻辑（他做决策的底层规则）

  1. 先算退路，再谈道义：任何一次出头，他心里都先过一遍"最坏结果能不能扛"。
  2. 对外示弱、留白、不说满：对皇帝永远"赤诚与赤忠" [第637章]，对敌人永远"给一次机会"再动手。
  3. 报复必须"体面"：要么明面立誓、要么当众摊牌，绝不无声无息。
  4. 对"自己人"不计成本，对"外人"精算利弊：这是他区分敌我的唯一开关。
  5. 抗拒被"赋予意义"：别人越想把他当旗子/神像/继承人，他越退——最终退隐。
  6. 以"母亲"为最高准绳：凡与叶轻眉之死相关，他会放下一切算计。

1.8 人物弧光一句话

从"独善其身的穿越者、只想活好的利己者" → 继承母亲济世意志、斩断父子枷锁的"复仇者与退隐者"。
他最终没有变成庆帝，也没有成为叶轻眉——他成为一个"愿意为自己人拼命、但拒绝为天下人成神"的普通人，这正是对"不羁之民"理想的另一种回答。

1.9 关键抉择时刻

  • 隐瞒林珙之死 [第100章]：明知对婉儿残忍，仍选择隐瞒——他护人的方式就是"替你背"。
  • 家法处置范思辙 [第287-290章]：亲弟也要断腕，体现"规则高于私情"的一面。
  • 当众打脸贺宗纬、列名单 [第710章]：宿敌用"毒针断肠"作结，是他"体面报仇"哲学的终点。
  • 对言冰云"我不原谅你" [第687章]：他可以为大局与旧友共事，但不肯假装原谅——原则不让步。
  • 送走王启年、不肯尽言以保范闲 [第582章] / 与范建共谋"第二内库" [第651-652章]：护人与复仇两条线并行。
  • 决定退隐西湖 [第745-746章]：拒绝了"当新朝柱石"的诱惑，选择"不受摆布"。

1.10 崩人设红线（续写对照）

  • ❌ 写成无脑热血、轻信他人 → 他骨子里怀疑一切。
  • ❌ 写成纯粹冷血 → 他对"自己人"的深情是底色。
  • ❌ 写成武力碾压的龙傲天 → 他的装备是"毒/狙/盟友"。
  • ❌ 写成大义凌然、甘为天下牺牲 → 他拒绝成神，是"退隐的强者"。
  • ✅ 正确味道：脸上笑嘻嘻、心里算盘响、遇自己人不要命、遇母亲之事不要命。

感情线逻辑：不是"恋爱脑"，而是**"志趣相投的谋士式夫妻"**——婉儿是范闲唯一能"坦白最深谋算"的人 [第404-406章]。她的成长线是"被保护的病弱少女 → 主动承担、有政治判断力的当家人"。

2.3 角色功能（三条）

  1. 情感锚/回家符号：范闲所有杀伐之后，"回府看婉儿"是他人性的归处。
  2. 身世纽带：她是长公主之女、庆帝外甥女，把皇权、后宫、范家、宰相林家四条线缝在一起，是全书政治网络的活结 [第103章][第330章]。
  3. 柔中带刚的"镜像"：她与范闲的关系，是"范闲渴望的平常人生"的具体化——所以结局是两人一同归隐，主题闭环。

2.4 崩人设红线

  • ❌ 写成纯粹柔弱、哭哭啼啼的工具人 → 她有政治敏感、能替范闲剖析后宫。
  • ❌ 写成宫斗心机女 → 她的"心机"只用在护家护夫，不争权。
  • ✅ 正确味道：病弱的身子、清明的脑子、倔强的心；对母亲长公主是"爱恨撕扯"。

附：主角线可复用规律（供续写）

  1. "穿越者+身世之谜"双引擎：现代记忆负责魅力与卖点（诗词/红楼），身世负责长线悬念与复仇动力。
  2. 能力与人格错位：他最强的不是武力，而是信息与人心——这让"爽"来自智斗而非碾压，耐读。
  3. 护崽开关："自己人"是唯一能让他失控的按钮，反复用于制造高潮。
  4. 复仇必须"体面"：明面立誓、当众打脸，是本书爽点的固定发动机。
  5. 女主是"网结"而非"花瓶"：让女主身兼血缘枢纽 + 情感归处，一鱼两吃。
